# BodyRef 實尺人台

輸入身高、體重、三圍和各部位量測，即時生成依真實尺寸換算的 3D 人台。

這個專案有兩個目的：

1. **讓數據有實體**：大部分 3D 軟體的體型調整用的是抽象滑桿（「胸部 +20%」），不是公分。這裡在模型上量到的每一圈，都等於你輸入的數值。
2. **讓描述可以對齊**：「160 公分、50 公斤、C 罩杯」到底長什麼樣子？與其各自想像，不如直接生成一個人台，截圖或分享代碼給對方看。適合當作 AI 產圖、角色設計、服裝打版時的體型參照。

## 功能

- **填你知道的就好**：每個數值不是「手動」（你填的），就是「推算」（依你填的數值與體型算出）。推算值旁邊列出一般人的常見範圍（約 10%–90%）。
- **體重跟著體型走**：預設不鎖體重。把腰圍改粗，脂肪會長在腹部、腰側，體重和體脂率跟著變重；手動鎖定體重時，多出來的脂肪會從其他沒填的部位扣回來（摘要卡會說明）。
- **罩杯只管胸部**：罩杯只改變上下胸圍差與胸型（小罩杯偏挺、大罩杯稍微下垂、更飽滿），不會拿腰圍或骨架去湊；也不會因為體重改變而變形。
- **比例**：腿長比（股下 ÷ 身高）、大腿：小腿、手臂長比、上臂：前臂。比例和四肢長度互斥：改比例時長度依比例推算，改長度時比例由長度算出。
- **現實檢核**：你填的每個數值，都會和「同性別、同身高、其他已填數值也相同」的人比較，列出它大概落在第幾百分位；模型做不到的組合（例如超出模型範圍的罩杯）也會列出。
- **3D 檢視**：白模人台（無五官的蛋形頭、有手指腳趾）；凹處（肚臍、腋下）稍微壓暗；以模型為中心旋轉、平移、縮放；正面／斜側／側面／背面一鍵回正；畫面上方的工具列切換結構線／網格／無、輪廓線、量測線與手臂角度。
- **輸出**：目前視角截圖、正交三視圖（同比例尺，附量測表）、分享連結與分享代碼。

## 怎麼做到的

### 1. 數值連動（`src/core/linkage.ts`）

把全身 18 項數據（身高、體重、體脂率、10 個圍度、肩寬、4 個長度）視為一個多變量常態分佈，長度與重量取對數。你鎖定的數值當作已知條件，其餘項目取條件期望值，條件變異數換算成常見範圍；少見程度也是同一套計算。

- **連動關係**（共變異數）來自 [ANSUR II](https://www.openlab.psu.edu/ansur2/)：2012 年美國陸軍人體計測，1,986 名女性、4,082 名男性，公有領域。
- **平均值**來自 `src/core/reference.ts` 的台灣／東亞年輕成人參考體型。
- ANSUR II 沒有量的項目用模型補上：體脂率由 BMI（Deurenberg 公式）加上腰、臀、二頭肌圍的偏差估算；下胸圍由胸圍減去上下胸圍差，胸圍差大多是個人差異、只有一小部分和體脂相關。細節寫在 `tools/prepare_stats.py`。
- 比例（`src/core/proportions.ts`）先換算成四肢長度，再交給連動模型。

### 2. 人體網格（`src/body/mh/`）

人體網格與形變目標來自 [MakeHuman](https://github.com/makehumancommunity/makehuman)（CC0）。網格是一整塊封閉的身體（約 13,000 個頂點），所以關節處沒有接縫。網格依「身體組成」分層變形（`model.ts`、`composition.ts`）：

1. **骨架**：身高（整體縮放）、四肢長度、肩寬，以及頸、手腕、腳踝、下胸圍這些以骨架為主的圍度。
2. **組成**：從偏瘦的基礎身體出發。肌肉分成手臂、軀幹、腿三段（和 InBody 的分段相同），各自混合 MakeHuman 的肌肉形變；脂肪分成 13 個堆積區（腹部、腰側、臀、大腿、上臂、胸……），每一區沿皮膚往外長一層，厚度 = 脂肪體積 ÷ 該區面積，所以肚子會往前凸，而不是整圈均勻變粗。體重 = 瘦體重 + 脂肪，體脂率由此算出。
3. **局部**：罩杯（MakeHuman 的胸部形變，挺度隨大小自然變化）。
4. **微調**：胸、腰、臀、臂、大腿、小腿的量測形變，代價很高，只補組成解釋不了的部分。

求解（加權高斯-牛頓法）時，手動填的數值要精確符合，沒填的只當作起點；每個參數只能影響自己負責的量測（例如罩杯只管上下胸圍差），體重則一定把所有形變算進去。新增的脂肪預設依性別分到各區（女性偏臀、大腿、下腹、胸；男性偏腹部、腰側、胸、背），手動填的圍度會把脂肪帶到對應的部位。

量尺寸（`measure.ts`）：圍度是用平面切出截面後的凸包周長，就像拉緊的皮尺；下胸圍與腰圍會跨過胸部下方。位置由關節與標記點決定，「最細處」「最粗處」在一段範圍內搜尋。

人台外觀：拿掉原本的頭，換成依頭部大小生成的蛋形頭（`egghead.ts`）；顯示前用 Taubin 平滑去掉細小凹凸，再依凹陷深度把凹處壓暗；手臂以骨架權重轉到指定角度。

這些都在 Web Worker 裡執行（`src/body/worker.ts`），拖動滑桿時畫面不會卡住。

## 準確度與限制

- 手動填的圍度與長度精確：測試會檢查六種體型（含誇張沙漏、偏胖、高壯男性、G 罩杯），網格上量到的數值和目標相差在 0.5 cm 內，鎖定的體重在 0.5 kg 內。
- 只填身高時，參考體型的體重與體脂接近參考值（測試檢查 4% 與 3 個百分點內）。
- 罩杯目前最大約到 H（MakeHuman 胸部形變的範圍），超過時會在現實檢核列出。
- 脂肪分佈是一般印象的預設比例，不是醫學資料；之後會加上 InBody 分段數據的輸入。
- 建議值是「統計上的典型」，不是唯一答案；ANSUR II 是美國軍人，連動關係套用到一般人時會有偏差。
- 量測位置與量法說明寫在每個欄位下方。上臂圍量在上臂中段；腰圍是肋骨與骨盆之間最細處；肩寬是左肩點經過後頸點到右肩點（服裝量法）。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 連動模型與網格的測試
npm run build    # 輸出到 dist/
```

需要 Node.js 20 以上。

### 重新產生資料檔

`public/body.bin`、`src/body/mh/manifest.json` 與 `src/core/statsModel.json` 都由 `tools/` 裡的腳本產生，需要 Python 3 與 numpy：

```bash
git clone --depth 1 https://github.com/makehumancommunity/makehuman /tmp/makehuman
python3 tools/prepare_body.py /tmp/makehuman/makehuman/data

# ANSUR II 的 CSV 可從 https://www.openlab.psu.edu/ansur2/ 下載
python3 tools/prepare_stats.py "ANSUR II FEMALE Public.csv" "ANSUR II MALE Public.csv"
```

## 部署

- `.github/workflows/ci.yml`：每次推送和 PR 都會跑測試與建置。
- `.github/workflows/deploy.yml`：發佈到 GitHub Pages。GitHub 免費方案只有**公開**儲存庫能用 Pages，所以目前設為只能手動執行。儲存庫改成公開（或升級方案）並在 **Settings → Pages** 把 **Source** 設為 **GitHub Actions** 後，把檔案裡的 `push` 觸發條件取消註解，推送到 `main` 時就會自動發佈。
- 想保持私人儲存庫又免費上線，可以改用 Cloudflare Pages、Netlify 或 Vercel 連結這個儲存庫：建置指令 `npm run build`，輸出資料夾 `dist`。

## 架構

```
src/
  core/                 與 3D 無關的數據層
    measurements.ts     量測項目的定義（名稱、量法、範圍），介面依這份清單產生
    reference.ts        參考體型、罩杯表、人體密度公式
    linkage.ts          數值連動：建議值、常見範圍、少見程度
    proportions.ts      身體比例與四肢長度的換算
    statsModel.json     由 ANSUR II 算出的共變異數（tools/prepare_stats.py 產生）
    analysis.ts         摘要數據與現實檢核
    state.ts            狀態、範例體型、瀏覽器儲存、分享代碼
  body/
    client.ts           主畫面與背景執行緒之間的橋梁
    goals.ts            把面板狀態換成網格求解的目標（哪些要精確、哪些只是起點）
    worker.ts           背景執行緒
    mh/                 MakeHuman 網格的處理
      asset.ts          讀取資料檔、套用形變目標
      geometry.ts       切截面、凸包、體積、平滑
      measure.ts        在網格上量尺寸
      composition.ts    脂肪堆積區與肌肉分段
      model.ts          依身體組成求解形變、擺手臂
      egghead.ts        人台頭與脖子
      guides.ts         結構線
      engine.ts         把以上組成畫面需要的輸出
  view/                 Three.js 顯示層
  ui/                   面板、摘要、匯出與分享
tools/                  產生資料檔的腳本
```

### 常見的擴充方式

- **新增量測項目**：在 `core/measurements.ts` 加一筆定義、在 `tools/prepare_stats.py` 對應到 ANSUR II 的欄位、在 `body/mh/measure.ts` 定義怎麼在網格上量、在 `body/mh/model.ts` 的 `CORRECTIONS` 指定用哪個 MakeHuman 形變目標微調，並在 `body/goals.ts` 決定沒填時要不要當目標。
- **脂肪分佈**：`composition.ts` 的 `DEFAULT_SHARE` 是新增脂肪分到各區的比例；InBody 分段數據可以直接換成這組比例。
- **型態指定（胸型、臀型）**：MakeHuman 已有胸部挺度、胸距、臀部體積等形變目標，加進 `tools/prepare_body.py` 的目標清單，再在 `model.ts` 當成使用者可調的參數即可。
- **姿勢**：MakeHuman 的骨架與蒙皮權重（CC0）可以直接用；目前只用來轉手臂角度。

## 授權與來源

- 人體網格、形變目標、骨架權重：MakeHuman 1.x 資產，CC0 1.0。本專案只使用其資產檔，沒有使用 MakeHuman 的程式碼（AGPL）。
- 人體計測資料：ANSUR II，美國政府公有領域資料。

## 規劃中

- 第二階段：型態指定（胸型、臀型）、肌肉線條（腹肌、人魚線、馬甲線，依體脂與肌肉量決定是「胖」還是「練」）、InBody 分段數據輸入、常用姿勢
- 第三階段：自訂動作、貼圖與皮膚、帶空間位置的三圍圖、AI 產圖用的深度圖／法線圖／骨架圖輸出
