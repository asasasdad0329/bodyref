# BodyRef 實尺人台

輸入身高、體重、三圍和各部位量測，即時生成依真實尺寸換算的 3D 人台。

這個專案有兩個目的：

1. **讓數據有實體**：大部分 3D 軟體的體型調整用的是抽象滑桿（「胸部 +20%」），不是公分。這裡每一圈量測線的長度都等於你輸入的數值。
2. **讓描述可以對齊**：「160 公分、50 公斤、C 罩杯」到底長什麼樣子？與其各自想像，不如直接生成一個人台，截圖或分享代碼給對方看。適合當作 AI 產圖、角色設計、服裝打版時的體型參照。

## 目前的功能（MVP）

- **少量推算＋逐項微調**：填身高、體重（可選體脂率、骨骼肌率、罩杯），系統推算出全身 15 項量測；知道實際數值的項目可以逐項改成手動，其餘繼續由推算補上。
- **體重驗算**：模型體重不是用公式套的，而是用 3D 模型的實際體積乘上人體密度（由體脂率換算）算出來的。手動指定的圍度和體重對不上時，會直接提示。
- **現實檢核**：腰臀比、腰高比、罩杯與體脂、腿長比例等組合若在現實中少見，會列出來並附上一般範圍。
- **3D 檢視**：白模外觀，以模型為中心旋轉、平移、縮放；正面／斜側／側面／背面一鍵回正；表面線條可選結構線（正中線、側縫線、公主線、頭部十字線）、網格或不畫；輪廓線、量測線可切換；滑鼠移到欄位上會標出該處的量測位置。
- **輸出**：目前視角截圖、正交三視圖（同比例尺，附量測表）、分享連結與分享代碼。

## 準確度與限制

- 圍度是精確的：模型在量測位置的截面，用「拉緊的布尺」量（凸包周長）會等於輸入值。測試會驗證這一點。
- 兩個量測點之間的曲線，以及由身高體重推算出來的數值，是「統計上的典型身材」，不是唯一答案。介面上會標示每個數值是「推算」還是「手動」。
- 參考體型（女性 160 cm／52 kg、男性 172 cm／68 kg）的模型體積和真實人體體積相差約 4% 以內（見 `npm test` 的校正係數測試）。
- 人台是抽象的服裝人台造型，沒有五官、手指與肌肉細節。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 模型與推算的測試
npm run build    # 輸出到 dist/
```

需要 Node.js 20 以上。

## 部署

- `.github/workflows/ci.yml`：每次推送和 PR 都會跑測試與建置。
- `.github/workflows/deploy.yml`：發佈到 GitHub Pages。GitHub 免費方案只有**公開**儲存庫能用 Pages，所以目前設為只能手動執行。儲存庫改成公開（或升級方案）並在 **Settings → Pages** 把 **Source** 設為 **GitHub Actions** 後，把檔案裡的 `push` 觸發條件取消註解，推送到 `main` 時就會自動發佈。
- 想保持私人儲存庫又免費上線，可以改用 Cloudflare Pages、Netlify 或 Vercel 連結這個儲存庫：建置指令 `npm run build`，輸出資料夾 `dist`。

## 架構

```
src/
  core/                 與 3D 無關的數據層
    measurements.ts     量測項目的定義（名稱、說明、範圍）。介面依這份清單自動產生欄位
    reference.ts        參考體型、脂肪分佈比例、罩杯表、體脂與密度公式
    estimate.ts         推算：身高體重 → 全身量測，並用模型體積校正體重
    analysis.ts         摘要數據與現實檢核
    state.ts            狀態、範例體型、瀏覽器儲存、分享代碼
  body/                 人台生成（只輸出座標，不依賴畫面）
    section.ts          截面形狀：超橢圓＋局部隆起，縮放到指定圍度
    loft.ts             放樣：把截面串成網格，計算體積
    generate.ts         由量測數據生成軀幹、頭、四肢、手、腳與量測線
  view/                 Three.js 顯示層
  ui/                   面板、摘要、匯出與分享
```

### 常見的擴充方式

- **新增量測項目**：在 `core/measurements.ts` 加一筆定義，在 `core/reference.ts` 補上參考值，再到 `body/generate.ts` 指定它影響哪個截面。介面、分享代碼、三視圖表格會自動帶入。
- **調整推算方式**：只需要改 `core/estimate.ts`（例如換成其他族群的統計資料、加入年齡）。3D 與介面不用動。
- **換素體**：`body/generate.ts` 輸出的是一組 `BodyShape`（各部位的網格、量測線位置、體積）。換成別的模型（例如帶骨架的 glTF）時，實作同樣的輸出即可，數據層和介面可以照用。
- **姿勢**：四肢的截面都定義在各自的骨段座標系裡（肩→肘→腕、胯→膝→踝），之後加姿勢時旋轉這些骨段再重新放樣即可。

## 規劃中

- 第二階段：型態指定（胸型、臀型、肌肉線條）、脂肪分佈比例、常用姿勢
- 第三階段：自訂動作、貼圖與皮膚、帶空間位置的三圍圖、AI 產圖用的深度圖／法線圖／骨架圖輸出
