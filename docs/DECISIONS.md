## 2026-10-25：數據討論（第一輪）

| # | 決定 | 理由 |
|---|---|---|
| 19 | **單向連動**：骨架類（身高、肢長、肩寬等）影響軟組織與總量的建議；軟組織、體重、體脂不影響骨架。手動填的骨架值要影響軟組織建議 | 骨架不應被胖瘦改變；main 現在把肩寬與其他部位完全切斷，兩個方向都不對 |
| 20 | **身高為錨點的組成鏈**：身高（＋手動骨架）→ 骨架 → 基礎去脂（骨、內臟、基礎肌肉，隨身高變化）→ 肌肉 → 剩下為脂肪。只填體重時，胖瘦預設分法用 NHANES DXA 的實測關係 | 改體重時只變軟組織；有去脂量隨身高變化的研究依據 |
| 21 | **骨架類圍度由骨頭推算**：每個骨架類圍度 = 骨頭寬度 ＋ 最少軟組織，影響範圍隨距離遞減（例如手腕影響前臂下段多、中段少）；軟組織厚度另由組成決定。下胸圍用骨架＋軟組織混合 | 讓控制區有實質依據；「骨頭 → 資料 → 基礎圍度」對照表列為基礎軌研究工作 |
| 22 | **介面保持少量、直覺的輸入**：不在介面上提示使用者用哪種方法量；量法與換算寫在手冊。複雜部位用內部控制＋代表型表達，不增加欄位。InBody 分段等多項輸入未來也不一定要做 | 作者不希望介面變亂，且很多細項使用者無法想像或換算 |
| 23 | **女性上胸圍預設為俯身量法**，不在介面提示，寫在手冊 | 補充 #16 |
| 24 | **女性腰圍填最細處**；男性腰圍可用肚臍高度 | 最細腰是女性體型最常用的表達；男性少有明顯最細腰 |
| 25 | **肌肉控制以推薦值為基準做增減**，不要求使用者直接填骨骼肌公斤；和體脂率在鎖定體重時互斥（擇一指定，另一個推算） | 骨骼肌公斤數一般人無從想像 |
| 26 | **上臂直接用放鬆臂圍**；建議值用 NHANES（同量法實測）。ANSUR 屈臂資料只在背後計算部位間的關聯 | 不用換算，也符合一般人的量法 |
| 27 | **女性腹部不加欄位**：最細腰決定腰側；體重、體脂決定肚子的量（小肚子、恥骨三角區、腹股溝轉折）；身高、骨架決定框架；腹型決定分布；資料以「同體重、體脂者的肚臍高度圍度」作軟偏好 | 符合 #22；D1 中「腰影響其他部位」的問題隨之簡化：腰只影響腰側 |
| 28 | **肌肉量決定體積與形狀，體脂率決定清晰度（乾／濕）**，不另設開關。精細刻線仍在延後清單 | 符合生理；不鎖體重時加肌肉體脂略降，鎖體重時明顯變乾 |

## 2026-10-25：變形軸的範本

| # | 決定 | 理由 |
|---|---|---|
| 42 | **每個部位（以及全身）都拆成變形軸**：脂肪、肌肉、骨架（例如胯寬）、型。「大小」與「等大小換組成」是脂肪與肌肉的組合：大小 = 兩者照常見比例一起增加（因此本來就不是等比放大），換組成 = 肌肉增、脂肪減、圍度不變。研究與塑型用脂肪、肌肉兩軸；數值控制可用大小方向。**修正 #39 的講法**：全身大小（身高、骨架寬窄、比例，長度與寬度分開）是獨立的形變；部位圍度是組合的結果 | 作者澄清原始想法：美型原模 → 漂亮的變形 → 連接數據；ANSUR 顯示長高時腿長增加約 1.2 倍、寬度與圍度只有 0.5～0.8 倍，證實變大不是等比放大 |
| 43 | **軸的範本研究前先定，每個部位實際用哪幾條、怎麼合併，研究後再定** | 範本來自「骨架、脂肪、肌肉、型」的基本生理事實，用來引導研究；研究可能發現某軸可省、某些區該合併或拆開 |
