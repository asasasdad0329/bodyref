## 2026-10-25：數據討論（第一輪）

| # | 決定 | 理由 |
|---|---|---|
| 19 | **單向連動**：骨架類（身高、肢長、肩寬等）影響軟組織與總量的建議；軟組織、體重、體脂不影響骨架。手動填的骨架值要影響軟組織建議 | 骨架不應被胖瘦改變；main 現在把肩寬與其他部位完全切斷，兩個方向都不對 |
| 20 | **身高為錨點的組成鏈**：身高（＋手動骨架）→ 骨架 → 基礎去脂（骨、內臟、基礎肌肉，隨身高變化）→ 肌肉 → 剩下為脂肪。只填體重時，胖瘦預設分法用 NHANES DXA 的實測關係 | 改體重時只變軟組織；有去脂量隨身高變化的研究依據 |
| 21 | **骨架類圍度由骨頭推算**：每個骨架類圍度 = 骨頭寬度 ＋ 最少軟組織，影響範圍隨距離遞減（例如手腕影響前臂下段多、中段少）；軟組織厚度另由組成決定。下胸圍用骨架＋軟組織混合 | 讓控制區有實質依據；「骨頭 → 資料 → 基礎圍度」對照表列為基礎軌研究工作 |
| 22 | **介面保持少量、直覺的輸入**：不在介面上提示使用者用哪種方法量；量法與換算寫在手冊。複雜部位用內部控制＋代表型表達，不增加欄位。InBody 分段等多項輸入未來也不一定要做 | 作者不希望介面變亂，且很多細項使用者無法想像或換算 |
| 23 | **女性上胸圍預設為俯身量法**，不在介面提示，寫在手冊 | 補充 #16 |
| 24 | **女性腰圍填最細處**；男性腰圍可用肚臍高度 | 最細腰是女性體型最常用的表達；男性少有明顯最細腰 |
| 25 | **肌肉控制以推薦值為基準做增減**，不要求使用者直接填骨骼肌公斤；和體脂率在鎖定體重時互斥（擇一指定，另一個推算） | 骨骼肌公斤數一般人無從想像 |
| 26 | **上臂直接用放鬆臂圍**；建議值用 NHANES（同量法實測）。ANSUR 屈臂資料只在背後計算部位間的關聯 | 不用換算，也符合一般人的量法 |
| 27 | **女性腹部不加欄位**：最細腰決定腰側；體重、體脂決定肚子的量（小肚子、恥骨三角區、腹股溝轉折）；身高、骨架決定框架；腹型決定分布；資料以「同體重、體脂者的肚臍高度圍度」作軟偏好 | 符合 #22；D1 中「腰影響其他部位」的問題隨之簡化：腰只影響腰側 |
| 28 | **肌肉量決定體積與形狀，體脂率決定清晰度（乾／濕）**，不另設開關。精細刻線仍在延後清單 | 符合生理；不鎖體重時加肌肉體脂略降，鎖體重時明顯變乾 |

## 2026-10-25：數據討論（第二輪）

| # | 決定 | 理由 |
|---|---|---|
| 29 | **研究資料庫按項目建立**：每個量一筆，記錄各來源（ANSUR、NHANES、台灣資料等）有沒有、量法、樣本，以及採用哪個、用途 | 不按資料庫來源一刀切分工 |
| 30 | **骨架因子**：看不見的「整體骨架大小」，由肩寬（為主）、手腕、腳踝相對身高推算，取代分層疊加生成。**長度類輸入只影響長度、不影響寬度**；軀幹長度由身高減腿長與頭頸推得 | 長腿不等於骨架寬 |
| 31 | **長度與組成的交互**：同樣公斤數分布在較長的肢段，截面較細（例：練壯但仍顯竹竿的長肢體型）；推薦圍度要隨肢長調整，並加「同體重、同組成、腿長不同」的測試案例 | 作者提醒 |
| 32 | **胯寬（髂嵴寬）放在「細節」群組**，預設收合、照預測值；它也決定瘦的人下腹兩側骨頭凸起的位置 | 骨架模型本來就需要骨盆寬，多出的只有量法與介面 |
| 33 | **骨性標誌與肌肉分界的清晰度都由體脂決定** | 與 #28 同一條規則 |

## 2026-10-25：數據討論（第三輪）

| # | 決定 | 理由 |
|---|---|---|
| 34 | **D1 收尾**：上臂（放鬆）透過 NHANES 完整影響其他建議；男性腰（肚臍）透過 ANSUR 完整影響；女性最細腰先換算成肚臍腰（附不確定性）再影響，不確定越大影響越弱；女性上胸不影響 | 量法一致的就完整影響；女性最細腰若完全不影響，填粗腰時體重建議不變，會長出「腰側粗、肚子小」的不合理形狀 |
| 35 | **最細腰與肚子分工**：資料以多因素（臀圍、髂嵴寬、脂肪量、內臟與皮下脂肪等）推肚臍腰與肚子的組成；最細腰由模型的骨架與腰側形狀自然形成，手動指定時只調腰側 | 沒有資料集同時量最細腰；統計推估只需毫秒，不影響效能 |
| 36 | **體脂建議改用 NHANES DXA 實測**，取代由 BMI 推估的人工值；優先使用亞裔樣本或以族群為變數 | 現行體脂是人工推估；NHANES 2011 年起加大亞裔抽樣 |
| 37 | **肌肉五等級**（偏少／一般／有運動／健身／壯碩，對應同身高同體重者的百分位），預設「一般」；細節群組可看、可填骨骼肌 kg；鎖體重時與體脂擇一指定。推薦值由 NHANES DXA 四肢去脂量換算骨骼肌 | 等級是相對值，不管身高都表達同一程度 |
| 38 | **脂肪堆積與肌肉成長的分區研究**：以 NHANES DXA 分區（手臂、腿、軀幹、腹部內臟／皮下、男性型／女性型區）取得各區隨總量的增加速度，男女分開；細分區（臀、下背、大轉子下方、大腿內側、肚臍周圍、恥骨區、膝內側、上臂後側、乳房等，參考解剖與訓練解剖文獻）以文獻與解剖推論補足，依據與可信度分開標示。產出「分區規則表」，作為形狀變化與總量分配的依據 | 之前的分配比例憑印象；作者要求有研究依據 |
