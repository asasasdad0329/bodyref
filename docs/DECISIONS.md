## 2026-10-25：變形軸的範本

| # | 決定 | 理由 |
|---|---|---|
| 42 | **每個部位（以及全身）都拆成變形軸**：脂肪、肌肉、骨架（例如胯寬）、型。「大小」與「等大小換組成」是脂肪與肌肉的組合：大小 = 兩者照常見比例一起增加（因此本來就不是等比放大），換組成 = 肌肉增、脂肪減、圍度不變。研究與塑型用脂肪、肌肉兩軸；數值控制可用大小方向。**修正 #39 的講法**：全身大小（身高、骨架寬窄、比例，長度與寬度分開）是獨立的形變；部位圍度是組合的結果 | 作者澄清原始想法：美型原模 → 漂亮的變形 → 連接數據；ANSUR 顯示長高時腿長增加約 1.2 倍、寬度與圍度只有 0.5～0.8 倍，證實變大不是等比放大 |
| 43 | **軸的範本研究前先定，每個部位實際用哪幾條、怎麼合併，研究後再定** | 範本來自「骨架、脂肪、肌肉、型」的基本生理事實，用來引導研究；研究可能發現某軸可省、某些區該合併或拆開 |

| # | 決定 | 理由 |
|---|---|---|
| 44 | **體脂內部一律用 DXA 尺度**（NHANES 實測）計算與顯示；使用者填的數值照填，不換算。手冊註明一般體脂計通常讀得比 DXA 低 | 作者：體脂的原意是一個和實際數值掛鉤的變形控項，不是 0～100 的抽象加減；尺度一致比對齊某一台儀器重要 |
| 45 | **肌肉五等級維持一般人口的百分位**（壯碩 = 第 97 百分位，約中位數 ×1.2）；更壯的體型在細節群組直接填骨骼肌 kg。形狀的肌肉軸要涵蓋到這個範圍以上 | 等級的意義保持一致（#37）；健美體型屬少數，用 kg 指定即可 |
| 46 | **欄位的數值就是內部定義的量法，內外統一**：使用者填的上胸圍、肩寬、臂圍、腰圍、體脂率等，直接當作用網站定義的量法得到的數字；不換算、不在介面提示量法。每個欄位的定義寫在 [量法手冊](MANUAL.md)，在意對應精度的人自己查 | 作者：控項的原意是和實際數值掛鉤的變形控制；大多數人只看造型，但對應關係仍要有依據。#22、#23、#26、#44 是這個原則的個案 |
| 47 | **修正 #20：基礎去脂隨身高與體型變化**。順序不變：身高（＋骨架）→ 骨架 → 肌肉 → 脂肪。基礎去脂（骨、器官、皮膚、結締組織）是看不見的內部帳目，由身高與目前的肌肉、脂肪量一起推算（NHANES：∝ 身高^0.4 × 骨骼肌^0.5 × 脂肪^0.15），用來把體重換算成脂肪與肌肉公斤數；不是形狀軸 | 第一批研究 R5：只看身高時，瘦的一端體脂誤差可達 10 個百分點；改用身高＋體型後，組成鏈和實測模型相差 0.5 個百分點內 |
| 48 | **修正 #30：不用統一的骨架因子，各分區單獨計算**。全身尺度由身高帶（寬度 ∝ 身高^0.5～0.8）；肩寬、胯寬、胸廓寬、關節粗細（由手腕、腳踝推）各自獨立，只影響附近部位 | 第二批研究 R6：扣掉身高與胖瘦後，肩寬和其他骨頭的相關 ≤ 0.2；肢端一組相關 0.3～0.5；胸廓、骨盆各自有個人差 |
| 49 | **修正 #31：竹竿感由身高的縮放產生**（同 BMI 時圍度 ∝ 身高^0.5～0.6、長度 ∝ 身高）；肢長比例只做小幅調整。測試案例「同體重、同組成、腿長不同」保留，預期為四肢圍度差不到 1 公分、軀幹略細 | 第二批研究 R11 |

## 2026-10-26：預先定錨與研究後的暫定項

| # | 決定 | 理由 |
|---|---|---|
| 50 | **數值定錨在做部位時預先算好（離線），網站只照預先做好的曲線變形**。每個部位在 ② 之後做 ③：沿各軸掃描、在網格上量圍度，整理成「數值 → 軸位置」的單調曲線或表，連同產生程式與誤差報告進倉庫。網站執行時只查表與內插，不在網格上反覆量測求解。胸部多一層：俯身胸圍由前傾姿勢的模擬預先算出，網站不模擬姿勢 | 作者一再要求的做法。執行快、結果和操作順序無關、可以逐點測試；舊做法在網站上反覆量網格求解，造成逾時與不穩定 |
| 51 | （暫定，作者：先照這樣算）**「只填身高」的預設體型用台灣年輕人中位數**：女 160 cm 約 54.5 kg（BMI 21.3），男維持 172 cm／68 kg | 第五批研究 R12；造型美感由原模與變形保證，與預設數值無關 |
| 52 | （暫定）**罩杯 = 俯身胸圍 − 下胸圍**，套現有每 2.5 公分一級的表；手冊註明大而軟的乳房會比店家尺寸大 | 第六批研究 R14；符合 #16、#46 |
| 53 | （暫定）**腹型軸 = 內臟脂肪占腹部脂肪的比例**，預設中位數（女 18%、男 30%）；肚子的量由體重、體脂決定 | 第三批研究 R9：皮下由體型決定九成，內臟有大量個人差，兩者幾乎不相關 |

## 2026-10-26：目標模與套回

| # | 決定 | 理由 |
|---|---|---|
| 55 | **各部位另外建目標模，原本的 MakeHuman 素體只當基礎模型**。構型、變化、數值都在目標模上做；最後把素體「套」到目標模上（逐格點算出素體的位移，存成預先算好的資料，#50），不在素體上手動改頂點。要修形狀就改目標模或套回參數再重新套。目標模共用同一個骨點座標框架，交界在目標模空間先接好。目標模的表示方式（提案）：骨架框架 ＋ 肌肉體 ＋ 脂肪層厚度圖，四條軸直接對應骨架、肌肉、脂肪、型 | 作者提出，用來根除 Codex 那種在素體上縫縫補補的做法。也是遊戲與影視角色的標準流程：先雕高品質的形狀，再包覆（wrap）到正式網格上，存成形變目標 |
| 56 | （已由 #57 修正：誤解了「線」的意思）**目標模用「控制線＋曲面」表示，三段流程**：(1) 先雕一個好看的中性型；(2) 依各條控制線（側面輪廓、背面輪廓、截面、臀溝、臀側凹陷等）做曲面形變，再把各軸整合，這一段不碰數據，只用研究得到的定性規則（附著線不動、哪裡先長）與範圍兩端（例如臀圍約 90～135、BMI 約 16.5～40）；(3) 套回素體、對應數據，對應不上就回頭修 (2)。生理推演決定控制線放哪裡、怎麼動。取代 #55 中「骨架框架＋肌肉體＋脂肪層」的提案 | 作者提出。控制線讓造型可以直接調、直接看，符合「先美型、再變形、最後接數據」；研究結果用來決定線的位置與動法 |
| 57 | **四個系統、依序做**：(1) **獨立 3D 模**（好看的中性型）；(2) **變形線**：每條線是一種生理變化的表面模擬，例如脂肪線（脂肪堆積如何改變形態）、肌肉線（肌肉增加如何改變表面），依生理特性推演後美化，不真的生成組織；(3) **數值控制**：在獨立模上把填表數值錨定到各線，例如 f(x) = a·x + c·y，函數連續、以離散格點錨定，對應不上回頭修 (2)；(4) **素體控制**：獨立的系統讓素體貼合變化模型，數值錨定完才做。「線」是產品線的意思，不是幾何曲線。修正 #56 | 作者澄清。數值錨定在獨立模上完成，素體只負責貼合，四個系統各自可以驗證、各自修；這也是作者早期考慮先做胸部的原因：胸部的數值控制多一層俯身換算 |
| 58 | **臀仍是第一個試做，用來驗證變形如何分線**（胸部線最少、最容易出成品，排在後面）。臀的數值線：脂肪增加、肌肉增加、脂肪與肌肉的比例、骨架大小（主要是寬度）；變形：脂肪堆積、肌肉堆積、兩者混合過渡，都隨骨架改變。混合值以 R19 為依據：臀圍每多 1 kg 約 55% 脂肪、45% 去脂，同臀圍的脂肪佔比個人差約 ±5～6 個百分點 | 作者：先做胸部容易出成品，先做臀是直接驗證線的拆法。臀圍變大不是等比放大，而是脂肪、肌肉各堆積多少 |
