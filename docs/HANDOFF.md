# 交接

接手只要讀四樣東西：

1. [VISION](VISION.md)：作者的理念與設計原則（要什麼）。
2. [PLAN](PLAN.md)：現行規劃（怎麼做）。
3. [工作區狀態總表](work/README.md)：做到哪。
4. 進行中的那一個工作檔：細節、紀錄、下一步。

決定與理由在 [DECISIONS](DECISIONS.md)；走過的路在 [HISTORY](HISTORY.md)；舊文件在 [archive](archive/)。
