# 解剖約束下的形狀控制提案

狀態：待討論，未實作。基準為撤銷三步交付後的 `f4e2aff` 應用程式；本次只回滾與提案，不啟用任何新形變。

## 目標與架構

保住原本可看的人體曲面，再改善女性腰腹、臀側與臀腿連接、女性預設胸型，以及男性胸臀。尺寸、體重與組成須對準；自然的曲面與連接同樣是交付條件。

目前稱作「形狀骨」的主要實作，是截面圈的方向縮放、PCHIP 連接曲線與權重位移。姿勢骨架另用於手臂蒙皮。它尚未在每個局部建立完整的造型控制骨與附著約束。新方案延伸這套截面控制，以局部控制籠承接胸部、臀部等需要更多方向控制的區域，保留原姿勢骨架。

每個局部控制必須定義：原始位置、可移動方向、附著邊界、影響頂點與連續權重、尺寸／體積響應。控制器處於中性狀態時，重現基準曲面。胸廓改變時，乳房底座及其控制座標一同移動；局部增減在這個座標內完成。

尺寸是對控制器的限制。先建立外型可接受的變形模式，再在這些模式中求解尺寸；不讓不合格的局部削平、尖峰成為達標出口。

## 解剖原則如何落到控制規則

| 結構原則 | 控制規則 | 檢查方式 |
| --- | --- | --- |
| 骨性支撐與筋膜附著限制表皮滑移 | 骨盆、胸骨、骶尾及根部等錨點保留基準關係；肌腹與覆蓋區允許增減，邊界平順回接 | 控制器位移圖、固定邊界與交界切線；不能挖低脊柱兩側製造新尖稜 |
| 肌肉受起止位置及肌腹分區約束 | 以肌腹厚度、寬度與分區控制增量；胸大肌的扇形解剖用來界定支撐範圍，不直接等同一塊扇形凸起 | 固定圍度比較肌肉模式；檢查胸骨、鎖骨與腋側過渡 |
| 皮下脂肪的厚度與附著分區影響表面 | 脂肪模式擴展覆蓋與低位飽滿區，跨相鄰控制帶連續分布；骨性框架不隨脂肪一起放大 | 正側後斜視與截面；不能只增高部位中心 |
| 乳下褶有多層筋膜與脂肪小葉結構 | 乳房根部、上胸過渡、內外側、胸峰與下極分開控制；下極能下移，底座不整塊向下搬，量測平面不當水平切刀 | 檢查上胸接胸廓、下極弧線、乳下褶與中央過渡；拒絕垂吊橢圓、長袋與規則深溝 |
| 臀部附著與脂肪厚度不等同單一臀肌輪廓 | 骶尾／骨盆支撐、臀後、臀側、轉子附近覆蓋及大腿根共同控制；臀下褶與臀肌下界分開 | 固定大腿圍增臀圍，仍應有正面側寬連動；檢查後腰窩與臀下接腿 |

解剖依據決定區域、方向與附著關係。具體位移幅度由自有 CC0 網格及逐個檢查過的造型校準，不把手寫比例說成研究提供的係數。

## 實作路徑

1. 保留既有網格。以現有截面及原網格的局部邊界建立控制籠；新增控制器不立即改變預設外型。
2. 為控制器產生連續影響權重，先以固定邊界的平滑權重求解建立原型，檢查影響範圍與交界，再決定是否需要細分控制點。新增的是有明確邊界的造型控制，不另疊一套任意圓頂覆寫原曲面。
3. 胸部保留原模型的完整曲面、上胸與下極差異，以底座、內外側、胸峰及下極控制增減。先建立小、中、大體積的合格關鍵造型，再測中間尺寸。命名胸型選單仍另作模組。
4. 每種形變都量測實際網格體積與尺寸響應，再接入公斤預算。重量記帳與表面控制分開測試；脂肪、肌肉、其他去脂量的新增記帳，不自行引入新的外觀位移。
5. 手動圍度由同一套受限控制重新對準；固定圍度的區域仍可交換脂肪／肌肉模式，但不能加厚後再用局部削洞抵消。未固定區的重量補償也只能走已檢查的控制模式。
6. 胸廓由骨架、肩部、下胸與原模型的連續形態控制，不增加「胸壁上圈等於下胸乘某比例」或「額外周長等於身高某比例」這類未校準硬目標。量測位置與胸部控制一起檢查，區分乳房下極與下胸量測路徑。
7. 求解未達標時定位控制範圍、量測或分配問題，修正該模式；不擴大負向參數範圍來接受壞形狀，也不把一般 E 罩杯標成生理上不相容。

## 分段交付

### 先固定基準與獨立介面項目

- 保存基準的固定視角、量測、局部截面與體積；相同條件都從這個基準比較，不能只與上一個已退步的中間版比。
- 比例介面另作獨立修改，使用 `1 : 比值`，不附帶改人體算法。肩點到手腕稱手臂長；臂展如列入，須定義為雙臂水平時左右指尖距離，不能拿服裝肩寬加兩條手臂假代。
- 獨立肌肉記帳先建立可測試的內部資料介面；相應表面控制未就緒前，不上線無實際作用的肌肉輸入。

### 第一步：女性腰腹、臀側與臀腿

- 先保留已改善的臀後曲線，建立腰、骨盆、臀側及大腿根的連續控制帶。
- 明確處理正面的「假胯寬」；增加臀圍時，臀後與臀側都能承擔變化，固定大腿圍不代表大腿根完全不動。
- 腰腹區分截面形狀、下腹飽滿及表面覆蓋；後腰維持骨性中線與兩側的合理關係。

### 第二步：女性胸部基礎

- 先在一般體型、B／E 罩杯驗證底座與整體曲面，再擴充 G／S；整個階段必須完成既定支援範圍。
- 上胸過渡、胸峰、下極及中央連接一起看；不以圓潤或消除尖角一項取代整體自然度。
- 驗證上胸不超過 100、腰不超過 65、臀至少 100 的 E 罩杯組合；另含小胸廓和偏胖體型，避免胸廓占掉罩杯差。

### 第三步：男性胸臀與組成整合

- 胸廓截面負責整體尺度，胸肌模式負責肌腹分布，脂肪模式負責覆蓋；三者在同一控制架構內校準。
- 同胸圍比較高低肌肉與體脂；增加胸圍時，前側與寬度連動，不把後背一起撐大，也不形成女性乳房式兩塊突起。
- 男性臀肌與脂肪採不同表面分布，保留骨盆、骶尾及大腿根連接。
- 最後接入獨立肌肉率與全身總量補償，重測固定多部位後增重；不以固定百分比把新增肌肉直接堆成胸前凸塊。

三步仍是完整目標，但各步獨立保存與驗證。原型階段先看少量有辨識力的圖；外型合格後才跑完整數值網格。尚未完成的區域維持基準行為，不一次替換全身。

## 驗收與發布

- 外型：同尺寸的正、側、後、前後斜視與局部放大，關掉量測／結構疊線；檢查上胸、乳下、臀下、後腰、側臀與大腿根。任一既有可看案例退步，就不以數字通過宣布完成。
- 幾何：控制邊界連續、無截面翻轉／不當穿插、沒有新的曲率尖峰；這些只能防幾何故障，不能取代外型判斷。
- 數字：手動圍度／長度 0.5 cm、體重 0.5 kg，明確指定的體脂／肌肉率各 1 個百分點內；組成總和與網格重量一致。
- 操作：同輸入不受歷史影響；比例與長度互斥／解除、保存分享、增重、組成交換及姿勢快取都須重測。
- 每段附基準對照，完成全部目標後跑整合回歸，再依專案既有 PR／部署流程發布。測試或截圖程式成功，不等同外型合格。

- [臀部三維形態的皮下結構](https://pubmed.ncbi.nlm.nih.gov/36519643/)：區域脂肪厚度、骶尾附著與臀褶附近纖維結構。用於界定控制與附著區，不推導通用增長比例。
- [乳下褶的筋膜結構](https://pubmed.ncbi.nlm.nih.gov/34998682/)：多層筋膜附著及脂肪小葉共同影響乳下輪廓，支持根部與下極分別處理。
- [胸大肌與胸部肌群的起止與形態](https://teachmeanatomy.info/upper-limb/muscles/pectoral-region/)：用於界定胸肌控制的支撐範圍；本文不提供體型預測係數。
- Seamscape 可作同條件多視角的外型交叉參考；不複製其模型、掃描資料、係數或程式，也不以其結果代替本專案的外型判斷。
