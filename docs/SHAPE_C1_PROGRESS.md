# C1：腰腹臀腿施工狀態

## 造型與連續變化

`lowerBodyShapes.ts` 在已標定的模型頂點上建立臀、腰、腹、大腿、小腿的小／中／大形態。材料來自倉庫既有的 MakeHuman CC0 有號雕形，另調整本專案需要的分布；沒有新增外部資產。參數 -1／0／1 是造型位置，尚不是公分或公斤。

- 臀：後凸與側向體量一起改變，下半臀與後／外腿根共同承接；原始單獨臀圍材料在臀下過於突兀，已補腿根分布。
- 腰：側向收束、前後厚度沿不同材料變化，接入上腹、後腰與上臀。
- 腹：前凸、側展、下腹分布共同變化，限制垂直下拉並接入骨盆前側及前／內腿根。沒有用單個法線鼓包。
- 大腿：前後內外側及整段肌腹分布，與臀下、側臀、骨盆前側、膝共同承接。原始單圈材料過度集中，已改成完整肌腹／覆蓋材料配合。
- 小腿：小腿肚、前側脛骨、膝與踝承接；降低原始材料在中段的集中，不整段等比放大腳掌。

端點間使用有共同切線的連續插值，端點外接同一切線。建立好的形態再拆回表面區塊對應的形狀骨；共享區域的權重不重複增量。大腿、小腿材料跟隨各自骨段的局部參照及長度；軀幹跟隨骨盆參照。

各部位已直接檢視小／中／大的正或後斜視及側視；範圍與單項控制檢查通過。新加的一項針對性測試確認共同形態與形狀骨重現一致，以及 -1／0／1 接點前後沒有跳位。沒有執行全身回歸或建立新檢查介面。
