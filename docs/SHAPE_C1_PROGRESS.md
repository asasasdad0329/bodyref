# C1：腰腹臀腿施工狀態

五部位已完成第一輪三維目標、連續肌脂變形與結構骨綁定，現在進行數值整合及修正；**整個 C1 尚未驗收，不能停止於此檢查點。**

## 實體成果

`assets/shapes/female-lower-body.blend` 保存女性臀、腰、腹、大腿、小腿的實際網格、30 個連續變形通道與驅動器。從 CC0 中性模型雕出目標，再依肌肉分布、皮下脂肪分層、附著與周邊承接建立變化，沒有以生圖建立變形，也未取用原生增重／肌肉 morph 代替本輪造型。

- 臀：後投影、側向、上／下飽滿及腿根承接分開；臀大肌、臀中肌外側支撐與皮下覆蓋不同。均衡／後側飽滿代表型已有造型通道。
- 腰：肋緣到骨盆的側面與後腰承接；脂肪覆蓋與肌肉的高度、前後分布不同。
- 腹：上腹、下腹、側向與腿根共同變化；柔和／平順腹型各有分布。處理過下腹接腿根的硬分界。
- 大腿：沿股骨的股四頭肌、內收肌、後側肌群與皮下覆蓋，向膝收束。
- 小腿：內外腓腸肌不同高度，比目魚肌銜接下段，保留脛骨前緣與跟腱。

已直接查看造型的正、側、背、斜視及尺寸中間狀態；美術觀察不以測試數取代。沒有新增產品檢查介面。各通道的幅度和權重是造型／工程假設，**不是論文推得的個人 cm/kg 生長率**。

## 數值整合進行中

`tools/export-lower-body-form.py` 匯出雕形資產和 Blender 獨立求值的混合樣本。`lowerBodyForm.ts` 綁至 B 已標定的模型區塊，使用既有 `LocalControlRig`，交界權重總和為一。`rings.ts` 的女性路徑使用新造型，移除對應的舊下半身圈縮放與軟組織疊加。男性暫維持原路徑。

既有體重／體脂／肌肉量分配先轉成區域公斤，再以實際曲面體積校準通道；圍度是曲面量測的求解目標，不直接等於形狀參數。代表型切換仍走同一求解。顯示、量測與體積目前使用相同原拓撲極限曲面樣本；高解析雕形到產品曲面的重現仍須完成外觀確認，不能冒稱二級細分曲面已完整上線。

已修正整合中把乳房表面混入胸壁的錯誤。修正後固定大臀／大腿及 18%／35% 體脂代表案例的首輪尺寸與幾何通過。158 公分／80 公斤仍暴露腰腹分配不足、腿部補償過多，正在回修覆蓋與數據映射；尚未完成全部 C1 案例、UI 與發布驗證。
