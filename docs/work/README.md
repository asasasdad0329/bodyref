## 工作檔的固定段落

每個部位的工作檔使用相同結構：

1. **範圍**：這個部位包含哪些分區、和誰交界。
2. **要求**：從 VISION 摘出這個部位的造型要求與已知問題。
3. **① 構型**：生理推演、目標造型的規則與參數、程式位置、自我檢查紀錄、作者看圖結果。
4. **② 變化**：大小軸、組成軸、型的變化規則、涵蓋範圍、序列圖紀錄、作者看圖結果。
5. **紀錄**：按日期記下嘗試過什麼、為什麼改、哪些被否決（避免下一個人重蹈覆轍）。
6. **結案**：完成時填寫。

## 結案的寫法

```
## 結案（YYYY-MM-DD，代理名）
- 完成了什麼：……
- 最終規則與參數：……（程式位置）
- 作者看圖結果：……（日期、圖的位置）
- 已知限制：……
- 留給下一步的事：……
```

圖片不進倉庫，只記錄位置（PR 連結、Actions 產物、對話日期）與觀察結論。
