# C2 女性胸部

狀態：未開始（C1 上線後開始）。

## 範圍

- 胸廓、乳房根部（底座）、自由乳房表面；交界：胸壁、上胸、腋側、胸骨中央、乳下到上腹。

## 要求

- 三種胸型：**水滴（預設）、長水滴／木瓜、圓潤**。共用同一組自由度：底座寬深、上下飽滿分布、內外展開、朝向、挺立／垂墜、胸距。不是三份互不相干的模型。
- 不以罩杯字母決定必須用哪一型；相同罩杯而上下胸圍不同，體量與造型也不同。
- 小胸不能靠把大胸削平取得；大胸不能變成扁片、長袋、球塊，也不能有肩胸溝。
- 切換胸型保持鎖定的尺寸與組成，只改分布與形態；體重未鎖時，胸部體量變化不能反過來啟動全身肌肉變化。
- 目標罩杯範圍：一般 A～F、小胸廓 E、G、現有大胸到 S；超過 S（到 ZZ）是之後的目標，本輪做的胸型自由度不能阻擋未來擴充。

## 胸圍定錨（作者 2026-10-24 指定，見 DECISIONS #16）

- 女性胸圍輸入是**俯身量法**的數字；模型輸出仍是自然站姿。這個輸入不等於站姿模型上任何一圈水平皮尺，不能拿站姿皮尺冒充。
- 先做好各胸型、底座、胸廓、體量下的連續變化，再建立上下胸圍、罩杯與其他數據的牽動，把俯身胸圍定錨到變化上。
- **預先定錨（DECISIONS #50）**：在 C2 的 ③ 用前傾姿勢的模擬，對每個胸型、體量、底座預先算出俯身胸圍，整理成「俯身胸圍、下胸圍 → 體量位置」的曲線。網站只查表，不模擬姿勢。研究依據見[胸部研究](../00-foundation/research-breast.md)。
- 保留獨立的俯身映射結果與站姿幾何指標；未經真人資料驗證前，不宣稱可精確預測真人量測。
- 下胸對應胸壁與根部，不穿過自由乳房。
- 量測語意變更要處理舊分享碼並說明。
