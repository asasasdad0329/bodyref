# D 全身總整

狀態：未開始（C1～C3 上線後開始）。

## 範圍

- 跨大區的交界：胸腹、腰臀、臀腿、肩臂。
- 全身分配：固定多個部位後增重、同尺寸不同組成、改罩杯／臀圍／肩寬／身高／比例時，不相關的部位不被意外驅動。
- 連續性：中間數值掃描、反覆鎖定與解除，不出現跳變。
- 上臂、小腿、頸等自由區的響應與分配責任（舊模型的固定 18% 手臂肌肉比例要修正）。
- 效能：冷算與重算不比基準慢超過 1.2 倍。
- 數據軌延後項目（推估欄位、肌肉比例、分配依據）視情況處理。

全身案例：各大區的固定案例組合，加上極端與常見體型各數組。
