## 3. D2：骨架與軟組織的連動方向（待作者決定）

- 作者觀點：骨架類不應牽涉軟組織。

## 7. 骨架推算提案（2026-10-25，討論中）

作者觀點：控制項有限；手腕圍最明確；肋骨應由肩寬與肩到腰的長度等其他數值取得；下胸圍與胯骨是骨與軟組織混合最嚴重的部位；頸椎、小腿骨還好；其餘可用最近控制點或複合控制點聯合計算；肩寬很大程度影響整體骨架大小。

提案的三層：

1. **骨架因子**（整體骨架大小，不是輸入欄位）：由肩寬（權重最大）、手腕、腳踝相對於身高推算。都沒填時取身高的常模。
2. **局部骨寬 = 骨架因子 × 最近或複合控制點的修正**：
   - 手腕 → 尺橈骨遠端（直接）
   - 腳踝 → 內外踝；頸圍 → 頸椎（直接）
   - 肋骨（胸廓寬、深）= f（肩寬、軀幹長度、骨架因子）；軀幹長度由身高與腿長推得，不新增欄位
   - 骨盆 = f（骨架因子、身高）；之後若開放胯寬則直接控制
   - 手肘、膝 = 骨架因子 × 鄰近控制點（手腕、腳踝）的複合
3. **混合部位的骨／軟分攤**（下胸圍、臀圍）：骨架部分由第 2 層給出，軟組織厚度由組成給出；手動指定圍度時，兩者依各自的不確定性分攤差額，各有上下限。

這些關係（例如胸廓寬與肩寬、身高的關係）以 ANSUR II 原始資料的骨寬欄位擬合，需先確認可取得的欄位。

### 初步檢驗：胸廓與胯寬能不能由骨架推得（2026-10-25）

以線性迴歸看可解釋的比例（R²）：

| 預測對象 | 只用骨架（肩寬＋背長＋身高） | 再加體重 |
|---|---|---|
| 胸廓寬 | 女 0.27／男 0.40 | 女 0.53／男 0.55 |
| 胸廓深 | 女 0.21／男 0.34 | 女 0.70／男 0.79 |
| 胯寬（只用肩寬＋身高） | 女 0.16／男 0.31 | 女 0.47／男 0.49 |

解讀：ANSUR 的胸廓、胯寬是在體表量的，含軟組織，所以加入體重後解釋力大增（尤其胸廓深）。這印證了作者的判斷：**胸廓與骨盆是骨與軟組織混合最嚴重的部位**；骨架部分由肩寬、背長、身高推，軟組織部分由組成推（#21 的混合算法）。

### 研究問題（引導研究，不決定結構）

依變形軸範本（DECISIONS #42），每個部位都問同一組問題：
- **脂肪軸**：該部位脂肪增加時先長在哪、往哪擴散、形狀怎麼變？
- **肌肉軸**：該部位肌肉增加時哪裡先飽滿、輪廓怎麼變？
- **骨架軸**：骨架寬窄（例如胯寬、胸廓）改變時形狀怎麼變？
- **組合**：該部位「變大」時脂肪與肌肉的常見比例（男女）？等大小換組成時看得出差別嗎？

全身層級的問題：

1. 總脂肪增加時，各區增加的速度與先後？男女、亞裔有何不同？
2. 哪些區會「一起變」、哪些「各自變」？這決定變量要分多細。
3. 減重時哪裡先消、哪裡最後消？
4. 肌肉增加時各區的差異？同一塊肌肉是均勻長，還是某些部位先長？
5. 細分區的位置、範圍，以及和粗區的關係？
6. 骨架寬度（胯寬、胸廓）和脂肪分布有沒有關聯？
7. 肢長不同、組成相同時，圍度怎麼變？
