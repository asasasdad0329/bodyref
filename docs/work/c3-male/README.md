# C3 男性

狀態：未開始（C2 上線後開始）。

## 範圍

胸廓、胸肌、胸脂；腹、下背；臀與大腿根。交界：胸骨、鎖骨、腋側、胸腹、下背到臀上。

## 要求

- 男女共用工程架構，但男性的表面形態、分布與增減方式各自研究、製作、驗證；不用女性乳房圓頂當主模式，也不是女性造型換倍率。
- 胸肌有自己的肌腹分布（胸骨、鎖骨到腋側的寬幅），脂肪有自己的覆蓋；肌肉型與脂肪型是連續條件，可共存。
- 偏胖男性（例如 170 cm／97 kg）：腹部要廣而前凸、胸下到小腹轉折柔和，下背到臀上連續，不能折出一道淺溝或分段起伏；胸前不能尖。
- 男性臀部有自己的分布與過渡，不沿用女性參數再縮小。

## 舊模型的已知問題（對照用）

- 偏胖男性下背有淺折痕；乳頭附近偏尖；腹部前凸集中、轉折偏硬（2026-10-19 與 2026-10-20 的觀察，當時版本）。
