# C1-1 臀（試做）

狀態：進行中（① 構型）。下一步：建臀的目標模（DECISIONS #55），先做「套回」的原型，確認素體的網格密度足以呈現目標模。

## 範圍

- 分區：臀上、臀後、臀側、臀下（左右），後腰下緣，大腿根外側與後側。
- 交界：後腰 → 上臀；側臀 → 外側腿根；臀下 → 大腿後側；薦尾正中與臀溝內側的附著。
- 腰、大腿尚未重做時，交界處和現有形狀平順銜接，等做到該部位再一起處理。

## 要求

- 後投影、側向展寬、飽滿位置（高低）、上下分布、過渡長度要能分別表達；臀圍是共同結果，不是一個後方圓頂的高度。
- 臀變大時，支撐範圍要跟著展寬、往上下延伸，不能只在固定範圍內把頂點推高（舊模型的圓塊問題）。
- 臀下褶可以保留，但不能磨平所有轉折，也不能變成固定的水平台階；臀下到大腿後側的承接要隨大小改變。
- 型：先做預設的「均衡飽滿」，再做「後側飽滿」。型代表「多翹、怎麼翹、肉在哪裡凸」。
- 涵蓋範圍：臀圍約 90～135（以 H 系列與 T3 為基準），偏脂肪到偏肌肉。
- 避免：球塊、臀下台階、後腰脊稜、外側腿根凹陷或尖錐、左右不對稱。

## ① 構型

### 起點與工具

- 基礎形狀：MakeHuman 基礎網格 + `asian-female-young`（亞洲年輕女性的平均）。數值上的預設體型是台灣年輕女性中位數，160 cm、約 54.5 kg（DECISIONS #51）。
- 算圖工具：`node tools/studio/render.mjs <倉庫外資料夾> [名稱]`。輸出全身與下半身多視圖，採霧面材質、斜射主光；也輸出頂點座標，供截面分析。圖不進倉庫。

### 生理推演（研究支持 ／ 造型假設分開標）

- **肌肉（解剖通論）**：
  - 臀大肌起於髂嵴後段、薦骨、尾骨，纖維往外下走，止於髂脛束與股骨臀肌粗隆，構成臀上中部的主要體積。
  - 臀中肌在髂嵴下方的上外側，構成上外側的飽滿（臀型的 A 點）。
- **皮下脂肪（文獻 R1b）**：臀下半與外側較厚；大轉子下方（B 點）是女性的堆積點；薦骨上方很薄，形成薦骨三角（V 區）與兩側腰窩（髂後上棘）。
- **固定的轉折（文獻 R1b）**：
  - 臀溝：內側半段明顯，往外漸淡；
  - 臀側凹陷（C 點，大轉子後上方）；
  - 薦尾正中。
- **中性臀型**：方形（A、B 一樣突），C 點有輕微凹陷（文獻 R1b 的臀型分類）。屬於造型選擇，作者看圖確認。
- **骨架**：胯寬改變臀的寬厚比，不改臀圍（骨架 R15）。中性狀態取台灣中位數比例。

### 基礎形狀的自我檢查（2026-10-26，作為起點）

- 側面：臀的後突量足夠，但最突點偏低；臀下緣接大腿處有一段軟的凹折，不夠清楚也不夠自然。後腰到上臀的弧線平順，上臀略平。
- 背面：臀溝內側有，但整體偏軟；臀部相對骨盆偏窄；腰到膝的外側輪廓接近直線，**沒有 C 點的凹陷**，也沒有 A、B 點的層次；外側輪廓最寬處落在大腿中段，偏低。
- 斜後方：臀的圓度可以，但臀側凹陷幾乎看不到；薦骨三角與腰窩不明顯。
- 正面：大腿接近圓柱，內外側沒有形態差異。這部分留給大腿（C1-4）處理。

### 做法（DECISIONS #55、#56）

- **目標模**另外建，不在素體上改頂點；用**控制線＋曲面**表示。
- **(1) 雕中性型**：控制線包括
  - 側面輪廓（後腰 → 臀最突點 → 臀下 → 大腿後側）；
  - 背面輪廓（腰側 → A 點 → C 點凹陷 → B 點 → 大腿外側）；
  - 幾圈水平截面（髂嵴、臀最突點、臀溝）；
  - 臀溝線、薦骨三角的邊線。
  曲面通過這些線並保持平順。
- **(2) 依控制線做形變**：每條軸（脂肪、肌肉、胯寬、型）定義各條線怎麼動，例如脂肪軸讓臀下半與外側的線往外，臀溝線位置不動只變深。各軸再整合；整合時另外算極端組合（最胖＋最壯＋最寬骨盆等），檢查互相干擾。這一段不碰數據，只用研究的定性規則與範圍兩端。
- **(3) 套回與對應數據**：素體臀區的頂點移到目標模表面上，保持網格間距；交界帶內位移平滑降到 0。在套回後的素體上量臀圍，對應數據。
  - 檢查標準：圍度隨大小單調、涵蓋範圍、胯寬改寬厚比而臀圍幾乎不變（骨架 R15）、套回誤差。
  - 對應不上就回頭修 (2)。
- **先做套回的原型**：確認素體的網格密度（約 1.3 萬頂點）表現得出臀溝等轉折。如果不夠、需要細分網格，那會改到網站的網格，屬於大改動，先問作者。
- 上面「基礎形狀的自我檢查」列的問題，改成中性型要滿足的要求。

### 這一輪的目標（待做）
