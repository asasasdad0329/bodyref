# C1-1 臀（試做）

狀態：待作者看圖（① 獨立模第一版，Blender 控制籠，DECISIONS #59）。下一步：依作者意見修中性型；之後依序做純脂肪線、純肌肉線、組成線、骨架線。

## 範圍

- 分區：臀上、臀後、臀側、臀下（左右），後腰下緣，大腿根外側與後側。
- 獨立模的範圍（#59）：臀圍控制的一整圈，髂嵴（下腰）到臀溝下約 6 公分的大腿根，前後左右都包含（下腹、胯下也在內）；不往上到腰背、不往下到大腿中段。
- 交界：後腰 → 上臀；側臀 → 外側腿根；臀下 → 大腿後側；薦尾正中與臀溝內側的附著。
- 腰、大腿尚未重做時，交界只在獨立模的上下緣；和素體的銜接是素體控制（第 4 步）的事。

## 要求

- 後投影、側向展寬、飽滿位置（高低）、上下分布、過渡長度要能分別表達；臀圍是共同結果，不是一個後方圓頂的高度。
- 臀變大時，支撐範圍要跟著展寬、往上下延伸，不能只在固定範圍內把頂點推高（舊模型的圓塊問題）。
- 臀下褶可以保留，但不能磨平所有轉折，也不能變成固定的水平台階；臀下到大腿後側的承接要隨大小改變。
- 型：先做預設的「均衡飽滿」，再做「後側飽滿」。型代表「多翹、怎麼翹、肉在哪裡凸」。
- 涵蓋範圍：臀圍約 90～135（以 H 系列與 T3 為基準），偏脂肪到偏肌肉。
- 避免：球塊、臀下台階、後腰脊稜、外側腿根凹陷或尖錐、左右不對稱。

## ① 構型

### 起點與工具

- 獨立模和素體無關（#55、#59）。尺寸的目標是台灣年輕女性中位數：160 cm、約 54.5 kg（#51），臀圍約 92.5（research-taiwan.md）。
- 建模：`blender -b -noaudio --python tools/blender/glute_model.py -- <倉庫外資料夾>`，用 Blender 4.2 LTS。輸出 `.blend`（控制籠與修改器都保留，可以在介面裡直接調）、`glute_model.npz`（設計截面點、擬合後的籠、細分後的網格、骨點）、`glute_measure.json`（各高度的圍、寬、厚）與多視圖。圖與輸出都不進倉庫。
- 雲端容器裡算圖要先裝 `libegl1 libgl1 libxi6 libxxf86vm1 libxfixes3 libxrender1 libxkbcommon0 libsm6 libice6`；EGL 的警告可以忽略。
- 舊的素體算圖工具 `tools/studio/` 保留，之後素體控制要用。

### 生理推演（研究支持 ／ 造型假設分開標）

- **肌肉（解剖通論）**：
  - 臀大肌起於髂嵴後段、薦骨、尾骨，纖維往外下走，止於髂脛束與股骨臀肌粗隆，構成臀上中部的主要體積。
  - 臀中肌在髂嵴下方的上外側，構成上外側的飽滿（臀型的 A 點）。
- **皮下脂肪（文獻 R1b）**：臀下半與外側較厚；大轉子下方（B 點）是女性的堆積點；薦骨上方很薄，形成薦骨三角（V 區）與兩側腰窩（髂後上棘）。
- **固定的轉折（文獻 R1b）**：
  - 臀溝：內側半段明顯，往外漸淡；
  - 臀側凹陷（C 點，大轉子後上方）；
  - 薦尾正中。
- **中性臀型**：介於方形與圓形之間（A、B 不強調，C 點只有很輕微的凹陷），臀峰在大轉子附近的高度，臀下半往內收、臀溝內側清楚。作者提供的胖瘦參考圖（只在對話中使用，不進倉庫）顯示：瘦的一端臀平、側面有凹陷；變大時不只往後突，也往兩側（胯與大腿根）、往下（臀下半與臀溝）、往腰側與下腹擴張。這是脂肪線、肌肉線要做到的事，中性型先不誇張。屬於造型選擇，作者看圖確認。
- **骨架**：胯寬改變臀的寬厚比，不改臀圍（骨架 R15）。中性狀態取台灣中位數比例。

### 基礎形狀的自我檢查（2026-10-26，作為起點）

- 側面：臀的後突量足夠，但最突點偏低；臀下緣接大腿處有一段軟的凹折，不夠清楚也不夠自然。後腰到上臀的弧線平順，上臀略平。
- 背面：臀溝內側有，但整體偏軟；臀部相對骨盆偏窄；腰到膝的外側輪廓接近直線，**沒有 C 點的凹陷**，也沒有 A、B 點的層次；外側輪廓最寬處落在大腿中段，偏低。
- 斜後方：臀的圓度可以，但臀側凹陷幾乎看不到；薦骨三角與腰窩不明顯。
- 正面：大腿接近圓柱，內外側沒有形態差異。這部分留給大腿（C1-4）處理。

### 做法（DECISIONS #57：四個系統）

1. **獨立模**：另外建臀（含交界的重疊帶）的 3D 模，做出好看的中性型。共用骨點座標框架（骨盆、髂嵴、大轉子、薦骨、髖關節）。
2. **變形線**（不碰數據）：
   - 脂肪線：臀下半與外側、大轉子下方先厚，臀側凹陷隨脂肪填平，臀溝位置不動只變深（文獻 R1b）。
   - 肌肉線：臀大肌、臀中肌整塊飽滿，上半臀與上外側（A 點）跟著飽滿（文獻 R2b）。
   - 骨架線：胯寬改變臀的寬厚比，臀圍幾乎不變（骨架 R15）。
   - 型線：A 字 ↔ V 字（全身型在臀的表現）。
   - 各線整合，另外檢查極端組合。範圍兩端：臀圍約 90～135、BMI 約 16.5～40。
3. **數值控制**：在獨立模上量臀圍，把填表數值（臀圍、體重、體脂、肌肉等級、胯寬）錨定到各線強度；連續函數、離散格點錨定。檢查單調、涵蓋範圍、胯寬不改臀圍。對應不上回頭修 2。
4. **素體控制**：素體臀區的頂點和獨立模表面建立對應，之後任何變形狀態下素體都跟著走；交界帶內平滑過渡。檢查素體量出的臀圍和獨立模一致、臀溝等轉折保留。如果素體網格太粗、需要細分，那是大改動，先問作者。

上面「基礎形狀的自我檢查」列的問題，改成獨立模中性型要滿足的要求。

### 線型（作者 2026-10-26，DECISIONS #58）

**四條變形線**（都是表面形變，決定模型怎麼變；不是數值）
1. **純脂肪線**：在中性型上不斷加脂肪或減脂肪，表面怎麼變。
2. **純肌肉線**：在中性型上不斷加肌肉或減肌肉，表面怎麼變。
3. **組成線**：固定某個維度（例如臀圍）不變，往肌肉換過去（或反過來往脂肪），表面怎麼變。
4. **骨架線**：脂肪、肌肉都不變，骨盆變寬（或變窄），表面怎麼變。

四條線各自是一段連續的表面形變，最後再整合；骨架線改變時，其他三條線的形變也跟著骨架調整。

**混合值的研究（R19，`tools/research/r19_glute_mix.py`）**

資料：NHANES 2017–2018 女性 20–59 歲，n = 967。DXA 的「女性型區」涵蓋臀與大腿上段，分開量了脂肪與去脂（主要是肌肉）。

- 臀圍由身高、臀區脂肪、臀區去脂可解釋 91%。在中位數附近，每多 1 kg 脂肪臀圍多約 4.7 公分，每多 1 kg 去脂多約 3.9 公分。脂肪密度較低，所以同樣公斤數撐得比較大。
- 臀圍從約 88 增加到約 137 公分時，臀區脂肪從 2.9 增加到 9.0 kg，去脂從 5.1 增加到 9.9 kg。**每多 1 kg，約 55% 是脂肪、45% 是去脂**，整段大致固定。
- 脂肪佔比的中位數從 37%（臀圍約 88）上升到 47%（約 137）：越大越偏脂肪。
- 同樣的臀圍，脂肪佔比的個人差（p10～p90）約 ±5～6 個百分點。這就是一般人口中「組成線」的範圍；運動員會超出。

這份研究屬於數值控制（第 3 步）與範圍的依據，不決定變形線怎麼變形：
- 組成線在同一個臀圍上要涵蓋的範圍：一般人口約 ±5～6 個百分點，運動員更多。
- 數值控制時，臀圍變大的「常見混合」是每 kg 約 55% 脂肪、45% 肌肉，用來把填表數值換成脂肪線與肌肉線的強度。


### 獨立模第一版（2026-10-26，#59）

**尺寸**（ANSUR II 女性 n = 1,986，各尺寸對身高與臀圍做線性迴歸，代入 160 cm、臀圍 92.5）

| 項目 | 目標 | 第一版量到 |
|---|---|---|
| 臀圍（水平最大，皮尺跨過臀縫） | 92.5 | 91.6（高 84.0） |
| 臀最突點高 | 81.6 | 82.5 |
| 最大寬 | 32.2（殘差標準差 0.9） | 33.0 |
| 臀部厚 | 20.6 | 20.5 |
| 大腿圍（臀溝下） | 55.0 | 53.5（高 72.5） |
| 髂嵴高、大轉子高、胯下高 | 97.5、82.9、77.0 | 籠的上緣 98、骨點與會陰按此擺 |

**結構**（`tools/blender/glute_model.py`）
- 只建左半，鏡像補右半；骨盆部分 6 層水平截面（98 到 79.2），每層 13 點，臀縫兩側用固定的 x 取樣讓臀縫窄而深。
- 胯下：最後一層的正前（恥骨聯合下緣）、正後（臀縫底）加上 3 個正中的會陰點，分成兩個腿圈；每條腿 4 層、每層 16 點，到 69.5。
- 截面參數：半寬、正前、正後、最寬處前後位置、前後半的方圓程度、臀峰（量、位置、內外側寬）、臀縫、臀側凹陷、腰窩；腿圈有中心、內外前後半徑、後外側圓度、臀下半往後的量、臀溝的收量。
- 細分 3 次。細分會把凸的籠往內收約 5%，所以籠會反覆往外補差值（補值先在籠上平滑，避免臀縫附近起波紋），讓細分後的曲面接近設計的截面。
- 骨點（左右）：髂嵴、髂前上棘、髂後上棘、大轉子、髖關節、坐骨結節、恥骨聯合、尾骨。是骨架線與素體控制共用的座標框架；目前是依高度目標估的位置，骨架線時再校。

**自我檢查（算圖 5 個視角：背、側、斜後、正面、斜前）**
- 背面：左右臀峰圓、臀縫窄；臀溝在內側明顯、往外漸淡、外端略往上，沒有橫跨整條腿的台階。腰窩很淡。
- 側面：下背的弧線接到上臀，臀峰在 82～84，臀下半往內收進臀溝，大腿後側平順往下。
- 斜後方：外側從胯到大腿根連續，C 點幾乎看不出來（中性型刻意很淡）。
- 量測：臀圍、寬、厚、大腿圍都在目標的 ±1.5 公分內；臀圍與大腿圍偏小一點，寬略大。
- 還有的問題：
  1. 截面是一層層的參數，層與層之間偶爾看得出極淡的橫向起伏（例如大腿根外側、正面胯下高度）。之後把參數改成沿高度的平滑曲線。
  2. 兩腿之間在胯下留了窄縫（大腿內側最近 0.35 公分），從背面看是一條細縫，上端圓。要不要讓大腿根貼合，看作者。
  3. 臀溝內端接到胯下的地方有小轉角。
  4. 正面只有下腹的弧與胯下，鼠蹊的斜線還沒做；這屬於下腹與大腿的交界，臀先不處理。
