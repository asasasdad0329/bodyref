# C1-2 腰

狀態：未開始。

## 範圍

- 腰側、後腰（左右）、上腹的側面部分。
- 交界：肋緣（上）、上臀與腹（下）。

## 要求

- 腰側適度收束；肋緣到骨盆的側面與後腰承接自然。
- 脂肪覆蓋與肌肉在高度、前後分布上不同。
- 收腰時前後覆蓋一起收，不能把脊柱兩側挖低形成脊稜。
- 細腰（56～68）時軀幹仍保有厚度，不能壓成薄片（截面下限）。
