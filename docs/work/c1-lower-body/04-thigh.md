# C1-4 大腿

狀態：未開始。

## 範圍

- 大腿根、大腿前／後／內／外（左右）。
- 交界：臀下、腿根、膝。

## 要求

- 前後內外各有形態，體量沿長度分布並向膝部收束。
- 不要方腿、均勻圓柱、根部突然收成尖錐。
- 左右腿根各自處理，不用同一個圓柱包住兩腿；內側不能穿插。
- 固定大腿圍時仍調整連接，不偷偷放寬該圈尺寸。
