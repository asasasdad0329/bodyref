# C1-3 腹

狀態：未開始。

## 範圍

- 上腹、下腹、骨盆前側。
- 交界：下胸、腰側、骨盆前與腿根。

## 要求

- 預設：上腹平順、腹前柔和起伏、下腹適度飽滿並接入骨盆與腿根。
- 腹部變大時前凸、側向展開、轉折深淺一起變；不能只有輪廓變寬而內部留著瘦體型的深窄分界，也不能中央鼓一包、兩側另貼幾塊。
- 下腹接腿根不能有硬分界。
- 型：柔和下腹、平順腹前（沿用 main 的兩種）。
