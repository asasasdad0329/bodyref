# C1 女性下半身（總覽）

部位順序：**臀 → 腰 → 腹 → 大腿 → 小腿**。每個部位先做 ① 構型、② 變化，全部完成後才一起接數值（[DECISIONS #6](../../DECISIONS.md)）。臀是整個新做法的試做部位。

## 範圍與交界

| 部位 | 工作檔 | 主要交界 |
|---|---|---|
| 臀 | [01-glute](01-glute.md) | 後腰（上）、側臀到外側腿根（側）、臀下到大腿後側（下） |
| 腰 | [02-waist](02-waist.md) | 肋緣（上）、上臀與腹（下） |
| 腹 | [03-abdomen](03-abdomen.md) | 下胸、腰側、骨盆前與腿根 |
| 大腿 | [04-thigh](04-thigh.md) | 臀下、腿根、膝 |
| 小腿 | [05-calf](05-calf.md) | 膝、踝 |

做後面的部位時，前面已完成的部位若需要配合交界調整，在該部位的工作檔記錄，不另開補丁。

## 舊模型的已知問題（作為對照，不是規格）

來自 2026-10-20 的比較測試，量的是當時的 BodyRef（`c0295fe`，PR #4 之前）：

- 臀後是固定範圍的圓頂：臀圍加大時只往後推高，中心、寬度、上下範圍不變。H104 起出現獨立圓塊，H124、H130 臀下接大腿越來越急。
- 偏胖時腰長太少、臀腿與上臂長太多。T4（158／80）腰 82.7、上臂 37.1、大腿 73.1；T7（體重 120）臀與大腿形成大量塊。
- 上臂兩頭偏：大臀、偏胖時太粗，鎖體重又要大胸臀時太細。

之後 PR #4 改善了分配，PR #13 重做了形狀層，但新的形狀層從未經作者看圖驗收。

| 組 | 輸入 | 用途 |

| H 系列 | 女，165 cm，上胸 97，下胸 76，腰 68；臀 94／104／114／124／130；體重不鎖 | 臀腰腿共同變化、大臀 |

| 固定多圈增重 | 165 cm，上胸 94，下胸 74，腰 68，臀 104；體重 60／75／90 | 分配容量 |
| T2 | 160 cm，50 kg，94／66／56／94 | 極細腰沙漏 |
| T3 | 165 cm，97／76／68／114 | 細腰大臀 |
| T4 | 158 cm，80 kg | 偏胖分配 |

① ② 階段用不到體重分配，可先用其中的尺寸範圍當造型的涵蓋目標。
