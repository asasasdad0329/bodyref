# 理念與設計原則

這份文件記錄作者對 BodyRef 的理念、偏好與已經表態過的設計立場。它是所有規劃與實作的上位依據：[PLAN](PLAN.md) 說「怎麼做」，這裡說「要什麼、為什麼」。

**修改規則：** 這份文件只在作者表達新的理念或修正舊立場時更新，代理不能自行改寫或刪減。實作時發現某條原則做不到，要在 [DECISIONS](DECISIONS.md) 記錄並向作者提出，不能悄悄繞過。

## 1. 產品是什麼

- **讓數據有實體**：輸入真實的身體量測（身高、體重、體脂、三圍、四肢圍度與長度），得到實際尺寸的 3D 人台。
- **給生成工具當體型參考**：主要用途是 AI 生圖（Agent 式、Reference 式，例如 Imagegen）與 3D 生成（例如 Tripo）的參照，也適合角色設計、描述對齊。
- **體模偏向美術，控制偏向實際數據。** 外型要自然、可信、好讀，可以有美術向的誇張比例；數字要精確、可核對。不是醫學模擬，也不是追求和真人掃描一模一樣。

## 2. 外型與身體的立場

### 2.1 整體觀念：像捏黏土

- **先有骨架，再在固定的位置貼上有重量的肉。** 脂肪、肌肉是「有固定部位的體雕」，不是均勻充氣。
- **總量一定要有地方去。** 體重與體脂決定脂肪、去脂的總量；手動填的部位用掉多少，其餘由沒填的部位承接。
- **手動填的數值是硬條件。** 沒填的才由分配決定；只有物理上不可能才算衝突。
- **截面有下限。** 例如腰圍 68 cm 一定裝得下內臟與必要的肌肉、脂肪，不能為了湊數字把身體壓扁。
- **同樣 BMI 可以長得很不一樣**（體脂低、肌肉多的人，和相反的人）。體脂率、肌肉量是重要輸入，不能一律變成均勻發胖的「泡芙人」。

### 2.2 比例與「型」

- **梨形、蘋果形、沙漏、H 形是三圍比例的結果，不是可選的型。**
- **可選的型只存在於局部部位**：胸型、臀型、腹型。只給少量代表型，不開放大量自由滑桿。
  - 胸型：把底座大小、胸部脂肪比例、肉的位置濃縮成幾種型。已約定三種：**水滴（預設）、長水滴／木瓜、圓潤**。
  - 臀型：指「多翹、怎麼翹、肉在哪裡凸」，不是全身比例。
  - 腹型：同樣是少量代表型。
- 同樣的尺寸與肌脂條件下，仍可選不同的型；型會隨尺寸、肌脂改變表現，但不會被求解器自行改掉。
- **男女分別建立形態**：男女共用工程架構，但表面形態、分布與增減方式各自研究、製作、驗證，不能共用造型再換倍率。

### 2.3 需要支援的體型範圍

- 非常規組合要能做：例如 60 多的腰配 100 以上的臀、70～80 的下胸配 90～100 以上的上胸。
- 非常規罩杯：目標最終支援到 ZZ 這類罩杯（目前約到 S，超過要靠胸型部件）。
- 長腿、長手等比例極端的體型，由比例輸入自然表現。

### 2.4 量法

- **腰圍**：最細處。
- **肩寬**：服裝量法，左肩點經過後頸到右肩點，不含上臂。
- **胯寬（骨盆寬）**：屬於骨架，和臀圍有連動；脂肪增厚不等於骨盆變寬。
- **女性胸圍**：以**俯身量法**的數字定錨，模型仍顯示自然站姿（2026-10-24 作者指定）。這個輸入不等於站姿模型上任何一圈水平皮尺。
- 骨架類數值（身高、肢長、肩寬等）原則上不受軟組織影響（D2 討論中，見 [基礎軌](work/00-foundation/README.md)）。

### 2.5 女性腰腹臀腿的造型要求

- 腹部預設：腰側適度收束、上腹平順、腹前有柔和起伏、下腹適度飽滿並接入骨盆與腿根。豐滿的胸臀腿可以和收束的腰腹並存。
- 腹部變大時，前凸、側向展開、轉折深淺一起變；不能只有輪廓變寬，內部還留著瘦體型的深窄分界，也不能中央鼓一包、兩側另貼幾塊。
- 臀：後投影、側向展寬、飽滿位置、上下分布、過渡長度要能分別表達。臀圍是共同結果，不等於一個後方圓頂的高度。
- 後腰到上臀、側臀到外側腿根、臀下到大腿後側是不同的承接。自然的臀下褶可以保留，但不能磨平所有轉折，也不能切成固定的水平台階。
- 大腿：前後內外各有形態，體量沿長度分布並向膝部收束。不要方腿、均勻圓柱、根部突然收成尖錐。
- 小幅凹陷、平面、皺褶不一律是錯；判斷標準是多角度能否一致地解釋，而不是「夠圓滑」。

### 2.6 參考與輸出

- 遊戲捏人系統（例如以大量形狀骨加平滑權重做到極端也不破圖的那類）是主要的方法參考：借鑑架構，不複製任何資產或數值。
- 預設顯示為中性灰霧面、柔和光；保留量測線、結構線的獨立開關；可輸出乾淨的單視圖與同尺度三視圖。

## 3. 做法的理念

- **內容先行，不是引擎先行。** 每個部位先有好看的造型，再有好看的變化方式，最後才用控制與數值去重現它。不能拿現有控制「做得到的」當目標，也不能為了遷就控制降低造型。
- **變化依生理學推演**：骨頭撐在哪、肌肉長在哪、脂肪怎麼堆、哪裡被附著拉住、會帶動哪些鄰區。研究支持的關係和造型上的假設要分清楚。**不得用生圖建立變形或當生理依據。**
- **變化是連續的，數值在連續變化上定錨。** 輸入的數字對應到變化路徑上的位置；增減時沿路徑前進。不能用自由參數湊尺寸而改壞既定變化，也不能把小造型線性外插放大。
- **看圖驗收，不以數字或測試全綠代替。** 每個階段要有圖，作者看圖決定。
- **實際數據要誠實**：推估欄位不能冒充實測；來源量法和網站量法要分開；達不到就明說。
