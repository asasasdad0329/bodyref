# 形態與尺寸控制的資料依據

## 用途與資料邊界

本輪實作兩個相互耦合的操作：以骨型、組成選擇表面形態；在該表面上量測並校正尺寸。使用倉庫既有的 MakeHuman CC0 網格與形變資產作造型資料，ANSUR II 作尺寸連動資料；下面的研究提供結構依據。沒有下載、訓練或複製受限制的人體掃描模型。

研究沒有提供能普遍套用的「脂肪／肌肉公斤 → 表面位移」函數。程式中的造型座標範圍、控制層位置與聯動強度，均是本專案的造型設定，須由自有網格的體積／尺寸量測和多視角檢查校準，不能稱為醫學回歸係數。去脂量含非肌肉組織，不能把去脂公斤直接標成骨骼肌公斤。

## 來源到規則

| 來源 | 可支持的結構原則 | 本輪對應與不作的推論 |
| --- | --- | --- |
| Han 等，2023，[臀部皮下結構](https://doi.org/10.1002/ca.23988)，Clinical Anatomy | 臀部形態受皮下脂肪、纖維附著、肌肉與骨架共同影響；骶尾與上臀／下臀的支撐關係不同 | 骨盆／骶骨作參照，臀後、臀側、下臀與腿根共享控制。高齡遺體研究不作年輕成人的增脂比例表，不把各區厚度直接換算成造型權重 |
| Guillier 等，2021，[MRI 與解剖的臀下褶研究](https://pubmed.ncbi.nlm.nih.gov/33462737/) | 臀下褶的內側附著具有纖維結構，不能只把臀肌下緣當成整條皮膚摺線 | 下臀與大腿根共用過渡；不生成一條水平切口。不同研究對具體骨性起點的描述有差異，本輪不將爭議點寫成唯一固定錨點 |
| Johnson 等，1996，[腹部皮下組織 CT／MRI／解剖](https://pubmed.ncbi.nlm.nih.gov/8838275/) | 腹部皮下脂肪有筋膜分隔，外表不能視為腹肌的一次均勻放大 | 腹前、腰側、後腰與覆蓋形態分開；本輪不模擬內臟脂肪，也不從全身體脂率宣稱反推出個人分層厚度 |
| Takaya 等，2022，[乳下褶筋膜結構](https://pubmed.ncbi.nlm.nih.gov/34998682/) | 乳下區由多層筋膜與脂肪小葉形成，不能簡化成單一肋骨高度的直接黏著 | 根部支撐與原乳房曲面分開控制；保留上下極差異，不使用皮尺平面切割下極 |
| Fung 等，2009，[胸大肌三維結構](https://pubmed.ncbi.nlm.nih.gov/19291757/)；[胸大肌解剖綜述](https://www.ncbi.nlm.nih.gov/books/NBK525991/) | 胸大肌具有不同起點與肌束分區，向肱骨附著；肌肉與乳房的造型結構不同 | 男性胸前由胸廓控制和既有男性肌肉形變描述，不套女性乳頭圓頂。起止點不直接變成一塊扇形隆起 |
| Qiao 等，2024，[三維形狀與分段組成](https://pmc.ncbi.nlm.nih.gov/articles/PMC11500346/) | 表面形狀包含超出少數圍度的組成相關資訊；形狀與組成有關但不一一對應 | 尺寸量測與形態參數分開，檢查同圍度不同組成。研究資料需申請，不採用其網格、模型權重或反向生成係數 |
| Heymsfield 等，2015，[組成參照模型綜述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4464774/) | Siri 雙組成模型採脂肪 0.9、去脂 1.1 g/cm³ 的計重假設 | 統一素體與增量密度，避免將去脂誤用單獨肌肉密度；以相同密度檢查總量能還原網格體積。這是雙組成計重模型，不是個人組織密度測定 |
| MakeHuman，[資產授權說明](https://static.makehumancommunity.org/makehuman/faq/are_makehuman_files_free.html)與[形變／蒙皮技術說明](https://static.makehumancommunity.org/oldsite/uncategorized/technical_notes_on_makehuman.html) | 核心形變資產為 CC0；網格有對應頂點，存在不同肌肉／胖瘦及胸部狀態 | 使用已入庫位移資產作造型基準，以非負、合計為 1 的權重混合。本專案獨立實作驅動與校正，不引入其應用程式碼 |

## 實作與驗收對應

- `shape.ts`：把組成條件映射到有界造型座標，混合既有 CC0 形變；罩杯不能改變全身形態起點。
- `shapeRig.ts`：形狀骨局部座標、相鄰控制的共享權重、腰腹臀腿根與胸廓的聯動；中性變換保留基準，剩餘權重屬於參照控制。
- `rings.ts`：對已選形態重新校準體積與圍度響應，於同一表面重測硬條件及自由組織補償；快取鍵包含形態。
- 體積記帳固定採去脂支撐在先、脂肪覆蓋在後的模式順序，兩次完整曲面體積之差記為脂肪增量；不假設 PCHIP 的組合體積線性。這是本專案的模式歸屬規則，並非從外表解剖分割出真實組織。
- 驗收分開保存固定尺寸的肌脂比較、尺寸序列、單控制／權重資料與無疊線多視角。數字通過不代表外型通過。

Seamscape 維持外型交叉參考用途。參考畫面與其他網站的資料不加入倉庫；本輪控制強度不宣稱來自 Seamscape 的掃描統計。
