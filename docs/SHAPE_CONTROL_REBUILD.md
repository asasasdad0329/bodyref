## B：控制設計與交界責任

控制採局部座標中的連續曲線／變換。父參照不只是檢視欄位：控制以框架給出的原點、三軸與尺度，將頂點轉到局部座標、求變換，再轉回。保留有效的既有方向性截面曲線。不同控制不能先按組織名合成單一幅度，組織分類只用於記帳與分配。

| 控制群 | 獨立內部能力 | 父參照與共享邊界 |
| --- | --- | --- |
| 腰腹 | 側向收束、前後深度、下腹覆蓋、前後飽滿高度 | 胸廓—骨盆縱向座標；胸腹、腰臀共用帶 |
| 臀 | 側寬、後投影、上下飽滿重分配、高度、向腿根的過渡長度 | 骨盆；後腰—上臀、側臀—外側腿根、臀下—腿後分別處理 |
| 腿 | 左右各自前後內外體量、肌腹高低、根部連接 | 髖—膝；根部不以包住兩腿的共同圓柱處理 |
| 女性胸 | 根部寬高、深度、上下極分布、朝向、胸距、垂墜 | 胸廓；根部與自由表面有連續綁定，不以胸峰圓頂外推 |
| 男性胸 | 胸廓寬深、胸肌腹、外下側覆蓋 | 胸骨—鎖骨—肩腋；禁止局部胸圈形成水平台階 |
| 肌肉 | 胸、背、臀、腿、臂分開，保留原生有號位移與收束 | 每區完整原生形態的分區合成；不將內收改成向外推，不延長臀肌到腿後形成第二肌腹 |
| 其他區域 | 小腿、臂、頸的有效方向控制與關節收束 | 各自關節軸；不是未驗證的體重出口 |

男女各有控制配置與完整形變路徑；不僅改幅度。型態改變控制的分布偏好，尺寸反求有限控制量。臀圍對多個控制的聯立響應與腰腿交界一起量測，不把每圈誤差固定按 50/35/15 或臀後／側各半永久分配。

## C–F：接受條件與證據約束

1. 建立確定起點；控制範圍先用單區掃描核對，未檢查範圍不能只因尺寸可達就視為有效。
2. 求解候選重新產生同一最終中性曲面，檢查尺寸、體積、組成、控制有效範圍及局部輪廓；失敗候選退回，不能在顯示層修掉。
3. 輪廓護欄針對已定位的故障：腿後額外肌腹、臀下短距離台階、肩胸尖折、胸部下極折返。不將自訂平滑度分數稱為解剖真值。
4. 形態／尺寸／組成都有效後才比較軟偏好；尺寸未收斂與組成互斥分別診斷。不把 90 kg 壓力案例刪掉或默降目標。
5. 每個型態單獨切換並檢查責任區，不能以全身任一頂點有變替代。固定腰臀腿配對需檢查不同高度的輪廓與交界。
6. 先數值再渲染固定快照，逐張記觀察；有限座標、無穿插、測試全綠、截圖數量均不等於外型通過。

- 共用局部控制已接入實際表面；骨性父參照運算、零權重邊界及控制順序不變性有測試。
- 臀上、臀後、臀下、側臀、腿根分開，肌肉保留有號原生材料，不把負法線投影截成外推；胸、背、臀不再共用同一幅度。
- 原生肌肉目標包含去脂收束，體積導數可能為負。因此不能把它直接當骨骼肌公斤導數。軀幹一單位使用素體骨骼肌估計量 35% 的工程範圍，胸／背／臀細分為 22%／50%／28%，不是 DXA 直接測得的肌肉；仍須與獨立肌肉案例、體積總帳及外觀共同校準。
- 區域分配正則化按控制響應尺度計價，防止小公斤斜率的控制以巨大倍率吸收誤差。臀與腰的初始份額隨條件及體積響應改變，後續分配可獨立調整各區。
- 新增曲面面積塌縮、四邊面折返與非有限座標護欄。這只涵蓋部分明確故障，尚未涵蓋自相交與所有不自然輪廓，不能以護欄通過代替外觀驗收。
- 型別檢查與 7 項控制／分享狀態測試通過；身體回歸、三型大小序列、數據重現、全身外觀與效能尚未完成。不得沿用 `289699e` 的完成宣稱。
