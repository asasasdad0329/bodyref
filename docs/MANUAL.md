# 量法手冊（草稿）

網站每個欄位的數值，代表下面寫的量法。介面不提示量法、也不換算；使用者填什麼，就當作用這裡的方法量到的數字（DECISIONS #22、#46）。在意對應精度的人看這份手冊。

狀態：草稿，隨各項研究與數值定錨補齊；「待定」的項目決定後更新。上線時整理成給使用者看的版本。

| 欄位 | 量法（數值的定義） | 依據 | 狀態 |
|---|---|---|---|
| 身高 | 赤腳站直，頭頂到地面 | ANSUR、NHANES | 確定 |
| 體重 | 空腹、少量衣物 | NHANES | 確定 |
| 體脂率 | DXA（雙能 X 光）測得的全身脂肪 ÷ 體重。一般體脂計（生物電阻）通常讀得比 DXA 低 | #36、#44 | 確定 |
| 肌肉 | 五等級：同身高、同體重的人當中的百分位（10／50／75／90／97）。細節群組可填骨骼肌 kg：以 MRI 為準的全身骨骼肌，由 DXA 四肢去脂換算（McCarthy 2023） | #25、#37、#45 | 確定 |
| 上胸圍（女） | 俯身量法：上身前傾約 90 度、胸部自然下垂時，過乳頭一圈 | #16、#23 | 罩杯定義待 C2（R14） |
| 胸圍（男） | 站姿、過乳頭水平一圈 | ANSUR | 確定 |
| 下胸圍 | 乳房下緣水平一圈 | — | 資料來源待 R18 |
| 腰圍（女） | 軀幹最細處 | #24 | 確定 |
| 腰圍（男） | 肚臍高度水平一圈 | #24 | 確定 |
| 臀圍 | 臀部最突出處水平一圈 | ANSUR | 確定 |
| 上臂圍 | 手臂放鬆下垂，肩峰到手肘尖（鷹嘴）的中點一圈 | #26（NHANES 量法） | 確定 |
| 肩寬 | 經後頸的服裝量法；內部和骨點肩寬互相換算 | 基礎軌第 4 節 | 換算待 R8 |
| 手腕、腳踝、頸、大腿、小腿 | 依 ANSUR II 的定義（大腿為臀溝下最粗處、小腿為最粗處） | ANSUR | 逐項確認後補寫 |
| 上臂長、前臂長、大腿長、小腿長 | 依 ANSUR II 骨點（肩峰－橈骨頭、橈骨頭－莖突等） | ANSUR | 逐項確認後補寫 |
