# 解剖參考如何轉成表面形變

本輪依序完成女性腰腹與臀腿、女性胸部基礎、男性胸臀。用途是繪畫與生成模型的人體參照；使用分區環切面與外表形變，不即時計算內部肌束或脂肪細胞。

## 共同規則

- 脂肪、骨骼肌、其餘去脂組織分開記帳。骨骼肌率可獨立輸入；沒指定時仍用去脂重量的 55% 作起點，不假設 ANSUR 有骨骼肌的共變異數。
- 每個區域有自己的支撐範圍與方向。脂肪增加覆蓋與較低的飽滿位置；肌肉沿肌腹增加，在骨性邊界與附著處淡出。這些是本專案美術參數，不是論文提供的人體預測係數。
- 手動圍度仍重新量測、校正；固定圍度也重新計算組成。固定體重時按實際網格體積修正，不能把尺寸相同當成體積相同。
- 其餘去脂量使用廣域支撐場作體積校正，不視為額外的骨骼肌。輸出脂肪、肌肉與其他去脂量之和等於總重量；超出可容納條件時保留殘差。
- 骨架快取與形態校準分開。形態校準包含體脂、肌肉、負重與臀圍支撐座標，不能沿用前一個形態的公斤響應。

## 表面區域

女性腰臀：臀側跨越骨盆外側至大腿上外側；臀後、腰側、後腰與下腹互相重疊支撐。增大臀圍須一起檢查正面寬度、側面投影與臀下接腿，不能只看側面。

女性胸部：MakeHuman CC0 底稿加上橢圓底座、偏下的飽滿位置、中央淡出與垂墜。`BreastFoundation` 是之後胸型預設的介面；本輪不提供水滴等命名選單。乳房脂肪另有區域公斤數，胸大肌支撐和乳房外形分開，改體脂後仍重做胸圍及重量校正。

男性胸臀：胸大肌用胸骨至肩側的扇形足跡，脂肪以胸廓覆蓋層向腋側與上腹淡出，不共用女性乳頭圓頂。臀肌偏上後方、有較短下緣，臀脂肪則使用較廣的覆蓋。

## 依據與使用界線

- [臀部三維形態的皮下結構（2023）](https://pubmed.ncbi.nlm.nih.gov/36519643/)：區域厚度及筋膜／皮膚附著影響外形。因此不把臀部當作單顆球，也不把臀下折線直接當成肌肉下緣。
- [臀部深層皮下脂肪分區](https://pubmed.ncbi.nlm.nih.gov/35977084/)：作為區域分布的補充線索，不複製解剖影像。
- [非均勻肌肉肥大研究](https://pubmed.ncbi.nlm.nih.gov/23657165/)：支持肌腹各區成長不同；研究對象為上臂，不能直接推出胸臀生長係數。
- [胸大肌解剖變異研究](https://pubmed.ncbi.nlm.nih.gov/31061824/)：用於理解胸大肌的扇形與分區，不以乳頭為肌肉生長中心。
- [增重時脂肪區域反應的差異](https://pubmed.ncbi.nlm.nih.gov/20921416/)：支持區域分配概念，不能單靠體脂率預測個人的精確外形。
