# 解剖參考如何轉成表面形變

範圍包括女性腰腹與臀腿、女性胸部基礎、男性胸臀。用途是繪畫與生成模型的人體參照；使用分區環切面與外表形變，不即時計算內部肌束或脂肪細胞。尺寸回歸、截圖產生與外型檢視是不同的檢查，不能互相代替。

## 共同規則

- 脂肪、骨骼肌、其餘去脂組織分開記帳。骨骼肌率可獨立輸入；沒指定時仍用去脂重量的 55% 作起點，不假設 ANSUR 有骨骼肌的共變異數。
- 每個區域有自己的支撐範圍與方向。脂肪增加覆蓋與較低的飽滿位置；肌肉沿肌腹增加，在骨性邊界與附著處淡出。這些是本專案美術參數，不是論文提供的人體預測係數。
- 手動圍度仍重新量測、校正；固定圍度也重新計算組成。固定體重時按實際網格體積修正，不能把尺寸相同當成體積相同。
- 其餘去脂量使用廣域支撐場作體積校正，不視為額外的骨骼肌。輸出脂肪、肌肉與其他去脂量之和等於總重量；超出可容納條件時保留殘差。
- 骨架快取與形態校準分開。形態校準包含體脂、肌肉、負重與臀圍支撐座標，不能沿用前一個形態的公斤響應。

## 表面區域

女性腰臀：臀側中心設在臀峰高度與胯下之間，支撐骨盆外側至大腿上外側；臀圍增加也展開上方支撐，不能只把低處的肉塊推高。收臀時作用於骨盆與大腿根的完整截面。收腰時側腹與前後覆蓋一起收，不以窄的負向肌腹削低脊柱兩側。臀後、腰側、後腰與下腹互相重疊支撐；驗收同時看正面寬度、側面、後腰與臀下接腿。

女性胸部：從 MakeHuman CC0 的最小乳房底稿取得胸壁，將胸壁位移與乳房體積分開。完整底座上的曲面處理前凸、中央分離、上下與側向展開，胸脂與尺寸使用同一體積座標。胸廓上圈、下圈及乳房聯合校正，防止用削扁乳房來抵消過粗的胸壁。下胸圍與腰圍在獨立胸壁表面量測，乳房下極可以跨過皮尺平面；胸峰依相對胸壁的前凸找出，不沿用中性素體的固定乳頭頂點。`BreastFoundation` 保留後續胸型模組的介面，尚無命名胸型選單。

男性胸臀：胸圍由上軀幹環切面對準，不能把尺寸差額全部堆到胸前；上方支撐區展開到胸廓上緣，並留出肩點過渡。未填的胸圍只追蹤軟偏好，不阻擋其他硬條件。胸大肌用胸骨至肩側的扇形足跡，脂肪以胸廓覆蓋層向腋側與上腹淡出，不共用女性乳頭圓頂。臀肌偏上後方、有較短下緣，臀脂肪則使用較廣的覆蓋。

原資產的下胸標記來自女性乳房蒙皮，下胸圍平面因此改為胸壁固定座標；男性則取胸點與下胸椎錨點之間的肋骨段。這是本專案的美術定位規則，沒有將它宣稱為實測量法換算。

## 依據與使用界線

- [臀部三維形態的皮下結構（2023）](https://pubmed.ncbi.nlm.nih.gov/36519643/)：區域厚度及筋膜／皮膚附著影響外形。因此不把臀部當作單顆球，也不把臀下折線直接當成肌肉下緣。
- [臀部深層皮下脂肪分區](https://pubmed.ncbi.nlm.nih.gov/35977084/)：作為區域分布的補充線索，不複製解剖影像。
- [非均勻肌肉肥大研究](https://pubmed.ncbi.nlm.nih.gov/23657165/)：支持肌腹各區成長不同；研究對象為上臂，不能直接推出胸臀生長係數。
- [乳下皺襞的筋膜結構研究（2022）](https://pubmed.ncbi.nlm.nih.gov/34998682/)：參考多層附著與脂肪小葉對下緣的影響；轉成根部與下極分別處理，不把皮尺平面當成水平截斷線。
- [胸大肌解剖變異研究](https://pubmed.ncbi.nlm.nih.gov/31061824/)：用於理解胸大肌的扇形與分區，不以乳頭為肌肉生長中心。
- [增重時脂肪區域反應的差異](https://pubmed.ncbi.nlm.nih.gov/20921416/)：支持區域分配概念，不能單靠體脂率預測個人的精確外形。

Seamscape 的掃描導向外觀僅作多視角連接的交叉參考，沒有採用其模型、資料、係數或程式。它的結果也不取代本專案的尺寸與美術驗收。
