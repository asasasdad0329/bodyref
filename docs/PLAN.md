## 2. 整體結構：兩條軌道

```
基礎軌（分區＋數據）：分區檢查與修正 → D1 連動行為、D2 骨架單向、肩寬換算、量測定義
                                         ↓（C1 接數值前要完成）
形狀軌：C1 女性下半身（臀 → 腰 → 腹 → 大腿 → 小腿，各做「構型 → 變化」）
          → C1 數值定錨 → C1 實測 → 上線
        C2 女性胸部（三種胸型）→ 俯身胸圍定錨 → 實測 → 上線
        C3 男性 → 數值定錨 → 實測 → 上線
        D  全身總整
```

兩條軌道可以平行；基礎軌的工作主要是數據與分區，形狀軌主要是網格造型，檔案幾乎不重疊。

## 3. 形狀軌：每個部位怎麼做

| 步驟 | 內容 | 完成條件 | 產出 |
|---|---|---|---|
| ① 構型 | 依 VISION 的造型要求與生理推演，做出這個部位的目標造型（中性的基準狀態） | 我自己算圖檢查到找不出問題後，**作者看圖確認** | 規則說明、產生形狀的程式（進倉庫）、四視圖 |
| ② 推演形狀變化 | 建立連續變化：「大小」軸與「脂肪 ↔ 肌肉」軸，型則是另一組變化。依生理推演：支撐、肌腹、脂肪堆積、附著、帶動的鄰區 | 全範圍序列圖中找不出問題後，**作者看圖確認** | 變化規則、序列圖（含截面） |

- 變化用**連續函數**表示：以規則函數為主，必要時加少量關鍵形狀平滑內插。
- 大小軸上的圍度必須**單調遞增**，數值定錨才有唯一解。
- 變化路徑要**涵蓋實際會用到的範圍**（例如臀圍約 90～135），不准線性外插小造型。範圍不夠就回頭延長路徑。
- 部位之間的交界在同一個網格上處理，不分開做再合併。
- 可以用 Blender（bpy）當算圖或幾何工具，但**產生形狀的腳本一定要進倉庫**，不能只放成品。

## 4. 大區做完全部部位後：數值定錨與實測

**數值定錨**
- 手動圍度：沿大小軸找到「量起來剛好等於輸入」的位置。只是搜尋位置，不改路徑形狀。
- 沒填的部位：總量分配決定該區公斤數，換算成路徑位置；分配參考統計建議（軟偏好）。
- 體脂、肌肉：決定在脂肪 ↔ 肌肉軸上的位置。
- 型：換一組變化路徑，定錨方式相同。
- 超出路徑範圍：明確報告，不偷偷外插。
- 接數值時發現某段變化不好看：回到 ② 修路徑，不在定錨層用參數湊。

**實測**
- 每個大區一組固定案例（不跑上百組的大矩陣），見各大區的工作檔。
- 數值門檻沿用：手動尺寸 0.5 cm、體重 0.5 kg、體脂 1 個百分點。
- 測試、型別檢查、建置、效能（不能比基準慢超過 1.2 倍）都要過。
- 看圖檢查清單：方腿、球塊、臀下台階、後腰脊稜、交界折痕、輪廓變了但內部轉折沒跟上、左右不對稱、胸部扁片或長袋、男性胸部女性化。

## 5. 作者看圖的時間點

| 時間點 | 看什麼 |
|---|---|
| 每個部位的 ① 構型 | 目標造型的四視圖 |
| 每個部位的 ② 變化 | 大小與組成的序列圖 |
| 每個大區的連動模擬 | 整區一起隨數值變化（數值定錨後） |
| 最後 | 全身案例 |

交給作者前，代理要自己先反覆算圖、檢查、修正；交出的是整理好的對照圖，附「看什麼、我自己檢查了什麼」的說明。

## 6. 分工與上線

- **形狀軌由同一個能看圖的模型連續做**（構型、變化是美術判斷加生理推演，便宜模型會在同一處失敗）。
- **基礎軌與機械性工作**（數據實作、測試、介面、效能）可以交給其他模型或另一個對話，前提是任務寫在工作檔裡、有明確完成條件。
- **分區上線**：每個大區（C1、C2、C3）實測通過、作者看過連動模擬後，合併並由作者發佈 Release。
- 第一個部位（C1 的臀）是**試做**：完成 ① ② 後一起評估品質、工作量，決定後續是否調整方法或分工。

## 7. 文件與紀錄規則

- **工作區**：每個大區、每個部位一個工作檔（見 [work/](work/README.md)）。進行中隨時更新；完成時填寫「結案」一節。
- **代理可直接更新**：PLAN 的狀態、DECISIONS 新增條目、工作區所有檔案、HANDOFF、HISTORY。這些是紀錄，不需作者逐次同意；照倉庫流程走 PR，CI 通過就合併。
- **需要作者同意才能改**：VISION 的內容、DECISIONS 裡已做出的決定、本規劃的結構（軌道、步驟、看圖點）。
- 圖片不進倉庫：放在 PR 說明、Actions 產物或對話中；工作檔只記錄圖的位置與觀察結論。
- 換對話或換模型時，只要讀 PLAN、工作區狀態總表，以及進行中的那一個工作檔，就能接手。
