## 2. 整體結構：兩條軌道

```
基礎軌（分區＋數據）：分區檢查與修正 → D1 連動行為、D2 骨架單向、肩寬換算、量測定義
                                         ↓（C1 接數值前要完成）
形狀軌：C1 女性下半身：臀先走完整條路（四條線 → 數值控制 → 素體控制 → 預覽網站，DECISIONS #65）
          → 腰 → 腹 → 大腿 → 小腿（各做「獨立模 → 變形線 → 數值控制 → 素體控制」）
          → C1 數值連動 → C1 實測 → 上線
        C2 女性胸部（三種胸型，預先算好俯身胸圍）→ 數值連動 → 實測 → 上線
        C3 男性 → 數值連動 → 實測 → 上線
        D  全身總整
```

兩條軌道可以平行；基礎軌的工作主要是數據與分區，形狀軌主要是網格造型，檔案幾乎不重疊。

## 3. 形狀軌：每個部位怎麼做

| 步驟 | 內容 | 完成條件 | 產出 |
|---|---|---|---|
| ① 獨立模構型 | 依 VISION 的造型要求與生理推演，**另外建這個部位的獨立 3D 模**（不是素體，DECISIONS #55、#57），做出好看的中性型 | 我自己算圖檢查到找不出問題後，**作者看圖確認** | 規則說明、產生形狀的程式（進倉庫）、四視圖 |
| ② 變形線 | 每條「線」是一種生理變化在表面上的模擬，依生理特性推演、再美化：**脂肪線**（脂肪堆積如何改變形態）、**肌肉線**（肌肉增加如何改變表面）、**骨架線**（例如胯寬）、**型線**。不真的生成組織，只模擬它們造成的表面變化。各線再整合，檢查極端組合。這一段不碰數據，只用研究的定性規則與範圍兩端 | 全範圍序列圖中找不出問題後，**作者看圖確認** | 各線的變形規則、序列圖（含截面） |
| ③ 數值控制（離線） | 在獨立模上把**填表的數值**錨定到各線：例如 f(x) = a·x + c·y，x、y 是輸入值，係數與曲線形狀是錨定的結果。函數是**連續的，用離散格點錨定**，格點間內插（DECISIONS #50）。胸部的俯身胸圍換算也在這一步 | 涵蓋實際範圍、單調、格點的誤差在門檻內；對應不上就回頭修 ② | 錨定程式、錨定資料、誤差報告 |
| ④ 素體控制（離線） | **獨立的素體控制系統**讓素體貼合變化模型：素體頂點與獨立模表面建立對應後，任何變形狀態下素體都跟著獨立模走。不在素體上手動改頂點 | 素體上量出的數值和獨立模一致（門檻內）、轉折有保留 | 對應程式、對應資料、誤差報告 |

- **變形軸的範本**（DECISIONS #42、#43）：每個部位與全身都拆成「脂肪、肌肉、骨架、型」幾條軸。「大小」= 脂肪與肌肉照常見比例一起增加；「等大小換組成」= 肌肉增、脂肪減、圍度不變。全身大小另有長度（身高、比例）與寬度（骨架寬窄）兩個方向，且不等比縮放。塑型時軸的強度用抽象的 0～1 表示，到數值定錨才校準成公斤、公分。每個部位實際用哪幾條軸，依研究結果決定。
- 變化用**連續函數**表示：以規則函數為主，必要時加少量關鍵形狀平滑內插。
- 用來定錨的變量（例如該區脂肪量）增加時，對應圍度必須**單調遞增**，數值定錨才有唯一解。
- 變化路徑要**涵蓋實際會用到的範圍**（例如臀圍約 90～135），不准線性外插小造型。範圍不夠就回頭延長路徑。
- 各部位的獨立模**共用同一個座標框架**（以骨盆、髖關節、髂嵴、大轉子、薦骨等骨點定位），交界處互相重疊一段，在獨立模的空間裡先接好，再由素體控制系統一起貼合。
- **不在素體上手動改頂點**：要修形狀就改獨立模或變形線，數值不對就改錨定，貼合不好就改素體控制系統（DECISIONS #55、#57）。素體（`public/body.bin`）不動。
- 可以用 Blender（bpy）當算圖或幾何工具，但**產生形狀的腳本一定要進倉庫**，不能只放成品。

## 4. 大區做完全部部位後：數值連動與實測

**數值連動**（網站上只查表，不在網格上反覆求解，DECISIONS #50）
- 執行時的流程：填表數值 → ③ 的數值控制（查表、內插）→ 各變形線的強度 → 獨立模的狀態 → ④ 的素體控制 → 顯示的素體。
- 手動圍度：用 ③ 預先算好的錨定，查出在目前的骨架、肌肉、型下各線的強度。只是在既定變化上找位置，不改變化的形狀。
- 沒填的部位：總量分配決定該區公斤數，換算成路徑位置；分配參考統計建議（軟偏好）。
- 體脂、肌肉：決定全身的脂肪與肌肉總量，照分區規則表分到各區。
- 型：換一組變化路徑與曲線，查法相同。
- 超出路徑範圍：明確報告，不偷偷外插。
- 接數值時發現某段變化不好看：回到 ② 修變形線、重算 ③ ④，不在連動層用參數湊。

**實測**
- 每個大區一組固定案例（不跑上百組的大矩陣），見各大區的工作檔。
- 數值門檻沿用：手動尺寸 0.5 cm、體重 0.5 kg、體脂 1 個百分點。
- 測試、型別檢查、建置、效能（不能比基準慢超過 1.2 倍）都要過。
- 看圖檢查清單：方腿、球塊、臀下台階、後腰脊稜、交界折痕、輪廓變了但內部轉折沒跟上、左右不對稱、胸部扁片或長袋、男性胸部女性化。

## 5. 作者看圖的時間點

| 時間點 | 看什麼 |
|---|---|
| 每個部位的 ① 構型 | 目標造型的四視圖 |
| 每個部位的 ② 變化 | 大小與組成的序列圖 |
| 每個部位的 ③ 數值控制 | 數值 → 形狀的對照圖（例如臀圍 90～135 每 5 公分一張） |
| 每個部位的 ④ 素體控制 | 素體貼合後和獨立模的對照圖 |
| 每個大區的連動模擬 | 整區一起隨數值變化（數值定錨後） |
| 最後 | 全身案例 |

交給作者前，代理要自己先反覆算圖、檢查、修正；交出的是整理好的對照圖，附「看什麼、我自己檢查了什麼」的說明。

## 6. 分工與上線

- **形狀軌由同一個能看圖的模型連續做**（構型、變化是美術判斷加生理推演，便宜模型會在同一處失敗）。
- **基礎軌與機械性工作**（數據實作、測試、介面、效能）可以交給其他模型或另一個對話，前提是任務寫在工作檔裡、有明確完成條件。
- **分區上線**：每個大區（C1、C2、C3）實測通過、作者看過連動模擬後，合併並由作者發佈 Release。
- 第一個部位（C1 的臀）是**試做**。2026-10-27 期中評估後決定（DECISIONS #64、#65）：
  - 臀先做完四條線與 ③ ④，放上預覽網站，通過後才做下一個部位。
  - 品質不限輪數；臀收尾時把作者歷次的看圖意見整理成共用檢查表與自動檢查，之後各部位交圖前由代理先自己過一遍。
- **素體控制的預案**（遇到再處理）：貼不回素體時，依序考慮 (1) 局部細分或法線貼圖、(2) 全面細分、(3) 自製完整體模，不到不得已不走 (3)。細分會放大網站的資料量，要和資料形式一起考慮。

## 7. 文件與紀錄規則

- **工作區**：每個大區、每個部位一個工作檔（見 [work/](work/README.md)）。進行中隨時更新；完成時填寫「結案」一節。
- **代理可直接更新**：PLAN 的狀態、DECISIONS 新增條目、工作區所有檔案、HANDOFF、HISTORY。這些是紀錄，不需作者逐次同意；照倉庫流程走 PR，CI 通過就合併。
- **需要作者同意才能改**：VISION 的內容、DECISIONS 裡已做出的決定、本規劃的結構（軌道、步驟、看圖點）。
- 圖片不進倉庫：放在 PR 說明、Actions 產物或對話中；工作檔只記錄圖的位置與觀察結論。
- 換對話或換模型時，只要讀 PLAN、工作區狀態總表，以及進行中的那一個工作檔，就能接手。
