# C1 臀部：第一個造型與變形

目前是女性「自然飽滿」臀型的第一份實體資產。完成目標曲面、肌肉／脂肪的連續造型進程，以及女性中性參照模型上的形狀骨重現；**不是全部臀型、C1 或產品交付完成**。尚未接臀圍、體重、體脂率或肌肉公斤。

## 先造型，再建立變化

`assets/shapes/female-glute.blend` 保存可直接編輯的三維曲面。以 MakeHuman CC0 中性女性網格作雕形胚體，重新塑造後凸、側向體量、下半臀及腿根承接；沒有使用既有增減臀圍、體脂或肌肉目標來決定美術結果。裁切的腰及腿部只供觀察周邊連接，不是產品裁切。

生圖沒有參與位移、權重、大小端點或變形曲線。先前錯用的生圖大小排列已排除，未存進倉庫。圖片不能建立或證明生理變形。

在該造型上分開建立兩條進程，並處理共同變化：

| 進程 | 曲面行為 | 保留的限制 |
| --- | --- | --- |
| 臀大肌體量 | 上、中、下臀的後側體量連續改變，沿外側附著與下緣退回周邊 | 不把局部增肌直接當成整腿肌肉同步增加 |
| 皮下脂肪覆蓋 | 後臀增厚，另改側臀、下半臀與近端後腿的覆蓋；增量不是後方單點鼓包 | 薦尾正中與臀溝內側的附著較受限，不固定整條橫向臀溝 |
| 肌脂共同承接 | 用同一連續交互項把共同增量延續到側臀與後腿根 | 不按個別尺寸增加補丁 |

Blender 物件屬性 `muscle_form`、`fat_form` 各為 −1 至 1 的**美術進程**。Shape Keys 共同構成 `S = S₀ + mDₘ + m²Qₘ + fD𝒻 + f²Q𝒻 + mfC`；曲面位置與切線連續。這個公式是保存已製作變形的工程表示，並非生理學推導出的生長方程。較小端點不模擬減重史、鬆皮或個人訓練反應。

## 解剖與生理依據、適用界線

- [Han 等，臀部皮下結構解剖研究](https://pubmed.ncbi.nlm.nih.gov/36519643/)：中央與側方的脂肪厚度不同，薦尾部及其他區域的附著也不同。用來約束分布與固定區，不能由少量標本直接得到通用的每公斤位移。
- [Stivala 等，臀下褶 MRI 與解剖研究](https://pubmed.ncbi.nlm.nih.gov/33462737/)：內側附著結構不能推廣為整條橫向硬折線。不同研究對起點的描述有差異，沒有把文獻中的骨性位置直接冒充本模型量得的頂點。
- [Plotkin 等，臀推／深蹲的縱向 MRI 研究](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2023.1279170/full)：臀大肌不同高度的增量可以與大腿肌群反應分開；肌電強度不等於長期肥大預測。該研究量的是特定受試者的截面，不提供站姿皮膚曲面位移公式。
- [Tchoukalova 等，過量攝食的區域脂肪反應](https://pubmed.ncbi.nlm.nih.gov/20921416/)：腹部與下半身脂肪的細胞增量機制有差異，不能把全身脂肪當成均勻膨脹。其股部結果不能直接當成臀部各點的增厚比例。

以上支持**分組織、分區域及附著約束**。本稿的位移幅度、覆蓋範圍、下極變化和交互量是明示的美術／工程假設，未經個人掃描校準，不是醫學模擬。臀中肌等條件、其他代表型及更大的完整尺寸域仍須繼續建立，不能把本稿外插後宣稱全範圍完成。

## 接回模型

1. Blender 資產保存原模型頂點對應及來源座標；裁切新增點不參與產品位移。
2. `tools/export-glute-form.py` 只匯出完成的造型通道及 Blender 實際求值樣本，不重新設計形狀。執行方式：`blender -b --python tools/export-glute-form.py`。
3. `gluteForm.ts` 將 549 個作用頂點分配到 B 已標定的臀上／後／側／下、後腰、側腰及腿根等 29 個區塊。共享權重合計為 1，由既有 `LocalControlRig` 共同重現；位移沒有因拆骨而重算。
4. 原有低模加平滑仍有臀峰與臀下折線，因此加入與雕形稿一致的二級 Catmull–Clark 極限曲面。`evaluateSurface()` 回傳真正幾何，並非只改顯示法線。後續數值定錨必須量這個曲面，不能使用低模量測、顯示另一個表面。

目前這條重現路徑尚未接入線上 `BodyEngine`、數據求解或 UI。框架尺寸變化、姿勢及效能在對應接入步驟處理；不能把女性中性參照的重現擴大解讀為已支援任意輸入。

## 本項查看與下一步

直接查看實體造型及結構骨輸出的後、側、斜視，包含單獨肌／脂的大小端點及共同變化，回修了臀下到後腿根的覆蓋。針對這項重現，使用 Blender 獨立求值的中間狀態核對控制點與臀部核心細分曲面；不是用同一段 TypeScript 產生預期答案。沒有新增視覺化檢查介面，也沒有執行全身回歸。

後續仍先補齊臀部所需的代表型與變形條件，再依序做腰、腹、大腿、小腿。C1 各部位都建立好才連結數值；C2、C3 與總整順序不變。
