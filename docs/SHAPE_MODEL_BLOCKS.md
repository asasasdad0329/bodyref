# 模型區塊與形狀骨的施工入口

本輪 B 的標定在 `src/body/mh/shapeBlocks.ts`，直接綁定 CC0 網格的頂點編號。女性參照用於定位；男女相同拓撲不代表共用造型規律。標定不隨輸入數字重新切區。69 個表面範圍不是 69 根骨頭；每個範圍的頂點、外緣、實際相鄰範圍、中心與邊界都可由同一份資料取得。

| 區域 | 模型上的範圍 | 造型需有的動作與共同交界 |
| --- | --- | --- |
| 臀 | `glute.upper/rear/lower/side.L/R` | 上下飽滿位置、後投影、側向展寬；後腰—上臀、外側臀—外腿根、臀下—後腿根分開承接 |
| 腰 | `waist.side.L/R`、`lumbar.L/R`、上腹 | 側向收束、前後厚度；上接肋緣，下接上臀與腹部 |
| 腹 | `abdomen.upper/lower`、`pelvis.front` | 上腹、腹前、下腹的前凸、側展、飽滿位置；連腰側與骨盆前側 |
| 大腿 | `thigh.root/body.front/back/inner/outer.L/R` | 前後內外不同分布，沿腿長收束；根部與臀腹共用，末端接膝 |
| 小腿 | `calf.front/back/inner/outer.L/R` | 小腿肚內外與後凸、前側脛骨輪廓；接膝與踝，不等比放大腳掌 |
| 胸 | `breast.free.L/R`、`thorax.front/side.L/R` | C2 再細分自由曲面、底座與胸廓的實際綁定；現有 breast 標籤僅為初始網格區，不宣稱是完整自由乳房範圍 |
| 背、肩臂與末端 | `thorax.back`、肩、上臂前後、肘、前臂、手、膝、踝、腳、頸頭 | 保留實際接鄰；輪到該部位再建立動作，不預填形變係數 |

上腹同時屬於腰與腹的共同範圍；臀下承接包含 `thigh.root.back`，側臀承接包含 `thigh.root.outer`。表面的主要歸屬不等於控制權重的硬切邊。C1 將在這些固定範圍及交界建立連續造型，再綁定形狀骨與數值。

本步確認：13,380 個身體頂點全部有主要歸屬，直接檢視正面、側面及背面的標定。這只確認 B 的位置，未把範圍標定當作造型完成。
