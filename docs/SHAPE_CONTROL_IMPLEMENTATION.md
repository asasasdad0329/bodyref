## 量法與輸入依賴

- 使用者最細腰、服裝肩寬、放鬆上臂與來源的肚臍／髂嵴腰、骨點肩寬、屈臂圍分開。ANSUR 的後三者不捏造固定公分換算。
- NHANES 2017–2018 的 DEMO_J／BMX_J／DXX_J 僅以同一期 SEQN 連接；成人 20–59 歲、有效體量、DXA 區域品質、MEC 權重及留出驗證。上臂為肩肘中點放鬆圍，DXA 整臂不等於上臂局部；DXA 去脂不改稱骨骼肌。
- 胸圍保持站姿水平皮尺語意；改善實際路徑與曲面響應，不引入未驗證的前傾轉換。下胸保留胸壁與根部路徑，不以自由乳房補足胸壁目標。
- 骨骼肌 kg 是獨立的模型估計成分。未指定肌肉時，使用明示模型先驗；改罩杯所增加的輸出體重不重新成為全身肌肉輸入。
- 明確尺寸只驅動本區與必要交界；脂肪／肌肉條件改變分布，固定圈仍重新對準。姿勢在中性曲面之後，不參與組成。

## 研究到控制的映射

下列是分區依據，位移幅度仍是工程／造型校準，並非論文提供的公斤係數。

| 來源與觀察 | 控制設計 | 檢查 |
| --- | --- | --- |
| [臀部皮下結構](https://pubmed.ncbi.nlm.nih.gov/36519643/)：區域脂肪厚度、上下部筋膜不同 | 臀上、後、側、下分區；骶部參照與後腰共同接續，臀側和腿根共享支撐 | 後斜視、臀下／腿根多高度截面，骨性中線不挖溝 |
| [乳下筋膜](https://pubmed.ncbi.nlm.nih.gov/34998682/)：多層附著結構 | 根部跟胸廓，上下極可重新分布；自由表面與附著漸變分工 | 胸根、下極、中央與腋側；不整塊下搬底座 |
| [胸大肌三維結構](https://pubmed.ncbi.nlm.nih.gov/19291757/)：鎖骨頭與胸骨頭及其肌腹分區 | 寬幅胸肌控制到腋側收束；胸脂採外下覆蓋，與胸廓寬深分開 | 固定胸圍肌脂配對，不使用女性乳峰圓頂 |
| [腹部皮下組織](https://pubmed.ncbi.nlm.nih.gov/8838275/) | 腹前、下腹、腰側共用連續帶；脂肪增加時同時改飽滿位置與覆蓋範圍 | 外輪廓與內部陰影一起看，不堆中央／兩側球塊 |
| [NHANES 量測](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/BMX_J.htm)、[DXA](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/DXX_J.htm) | 實測放鬆臂偏好、粗分區組成先驗；與 ANSUR 各自求條件值 | 留出驗證、適用範圍與區域映射，統計不取代手動尺寸 |

全身父參照：胸廓→肩／胸根／上背；胸廓與骨盆→腰腹；骨盆與骶部→臀；髖與膝→左右腿根與大腿；肩肘腕→上臂前臂；膝踝→小腿。交界由相鄰權重共同合成一次，不重複計量。

## 已落實的共同規格

- `controls.ts` 登錄局部軸、父參照、支撐、範圍及拓撲權重。前腹／下腹、後腰、臀上後側下、腿根共用表面合成。男性胸脂是有限薄覆蓋，胸廓尺度及原生 CC0 肌腹曲面各自負責；男女使用各自原生目標與控制帶配置。
- 原生 maxmuscle 同時含去脂收束，不能直接用其淨體積當肌肉公斤。肌肉量控制取向外肌腹及少量切向展開，去脂收束由脂肪帳另行負責；每種模式在相同中性框架重新校準實際體積響應。
- 女性大小從原生小杯開始，插值至中、大杯，再擴展同一控制籠；不以負參數削大胸得到小胸。三型共享寬深、上下極、展開、下移控制。原網格下極放大後的曲率校正在同一控制支撐內進行，尺寸和體積量測均在校正後。
- 下胸 v2 量測同一框架與軟組織上的胸壁參照，避免自由乳房垂墜到皮尺平面時把乳房當胸壁。胸壁參照及自由表面都經相同中性平滑，皮尺獨立計算；另記自由表面水平下胸供診斷。上胸維持站姿實際水平皮尺，不採未驗證的前傾轉換。
- 手動尺寸是硬條件；未填框架值是起點／參照，不因推估頸圍碰界限而卡死分配。局部聯立校正只在責任區內處理胸／下胸、腰臀腿等交互。固定根部圍度仍有下腹覆蓋與大腿中段的形態容量。
- 體重未鎖時，推估重量不再反推新的全身肌肉／器官量；去脂先驗由身高與參照框架建立。明確肌肉量獨立操作；固定體脂／重量時重新校正組成，其他去脂不任意改密度。
- 脂肪密度固定 0.9 g/cm³，骨骼肌與其餘去脂採 1.06 g/cm³ 的模型近似；素體和增量使用同一混合密度，不混用 Siri 假設。總帳直接與最終網格體積閉合。乳房新增體積採 85% 脂肪、15% 其餘去脂的工程先驗，不算骨骼肌；這不是從圍度辨識真人組織比例的醫學模型。
- NHANES 上臂留出 MAE：女性 1.2635 cm（訓練 762／留出 207），男性 1.5647 cm（784／198）。整臂／腿／軀幹組成只作粗分區先驗，局部與全身覆蓋的映射仍屬工程模型；不把整臂重量全部指定到上臂。
- 肚臍採原網格自有標記頂點 4121；最細腰與肚臍腰分別量測。兩者的基準差僅用於本網格的幾何偏好對應，不宣稱真人通用換算。最細腰保留較弱的造型偏好；手動最細腰不當 ANSUR 肚臍腰觀測。服裝肩寬採參照框架尺度，不套用骨點直線共變異；這兩者及人工體脂不顯示假實測百分位。
- `tools/control-inspector.html` 可檢查單控制、權重、光向及停用單一組織後的實際解。`test:shape-report` 固定來源與資產雜湊，產出正／前斜／側／後斜／後視；產出途中來源變更即拒作同版本證據。`test:ui` 實際操作分享、型態、肌肉、比例互斥、乾淨圖片與手機排版。
